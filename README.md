## 2. 필요한 파일과 실행 환경

실행할 파일은 `Prospi26Studio.Single.exe` 하나입니다. README는 안내 문서이며 실행에 필수인 파일은 아닙니다.

- Windows x64 환경과 해당 PC 게임
- **.NET 6 Desktop Runtime x64**
- **Microsoft Edge WebView2 Runtime**

런타임이 없다면 아래 Microsoft 공식 페이지에서 설치하세요.

- [.NET 6 다운로드](https://dotnet.microsoft.com/en-us/download/dotnet/6.0): `Run apps - Runtime` 아래 **.NET Desktop Runtime 6.0.36 → Windows → x64**를 선택합니다. SDK나 ASP.NET Hosting Bundle을 고르는 것이 아닙니다. Desktop Runtime에는 기본 .NET Runtime도 포함됩니다.
- [WebView2 다운로드](https://developer.microsoft.com/en-us/microsoft-edge/webview2/): 일반 사용자는 **Evergreen Runtime** 설치 항목을 이용하면 됩니다.

현재 Studio는 .NET 6을 사용합니다. **.NET 6은 Microsoft 지원이 종료된 버전**이며, 이번 단일 파일 패키징에서 최신 런타임으로 전환된 것은 아닙니다. 자세한 상태는 위 공식 다운로드 페이지의 지원 종료 안내를 확인해 주세요.

단일 EXE라고 해서 런타임까지 모두 포함된 것은 아닙니다. 첫 실행 때 내부 파일을 전용 캐시에 풀고 검사하므로 잠시 기다려 주세요. 이후에는 캐시를 검사해 재사용합니다. 게임 설치 폴더에 파일을 덮어쓸 필요는 없습니다.

## 3. 빠른 시작

1. 게임 세이브를 백업합니다.
2. 다른 Studio·트레이너·CT를 사용하고 있었다면 기능을 끄고 **정상 종료**합니다.
3. 게임을 실행하고 사용할 모드의 세이브를 불러옵니다. 선수·구단을 찾을 때는 해당 모드의 메인 화면이나 명단 화면에서 진행하세요.
4. `Prospi26Studio.Single.exe`를 한 번 실행합니다.
5. Studio에서 게임 인식과 호환성 상태를 확인합니다. `게임 대기`, `BUILD LOCK`, `새 빌드 잠금` 상태라면 바로 기능을 켜지 마세요.
6. 사용할 모드로 이동하고, 구단·선수 선택이 필요한 기능은 현재 명단을 불러와 대상을 확인합니다.
7. 원하는 값을 입력한 뒤 해당 기능의 **적용 또는 ON 버튼**을 누릅니다. 체크하거나 숫자를 입력하는 것만으로 적용되지 않는 항목이 있습니다.
8. 게임에서 변화가 있는지 확인합니다. 목록이 갱신되지 않았다면 해당 화면을 나갔다가 다시 열어 확인하세요.

## 5. 체력·컨디션·수량 등의 자동 유지

1. 사용하는 모드와 유지 대상을 확인합니다.
2. 필요한 유지 항목과 값을 선택해 적용합니다.
3. **페넌트는 `자동 유지할 페넌트 내 구단`을 별도로 확인하세요.** 지금 명단에서 보고 있는 구단과 유지 대상으로 지정한 구단은 다를 수 있습니다. 유지 중 구단 변경이 막혀 있으면 해당 유지 기능을 모두 끈 뒤 바꿉니다.

유지 기능은 주기적으로 상태를 확인하고, 이미 목표값이면 불필요한 쓰기를 줄이는 방식입니다. 값이 바뀌면 다음 정상 처리 주기에 다시 확인합니다. 모든 항목을 변화 순간에 지연 없이 수정한다는 뜻은 아닙니다.

- `유지 수치 지금 재검사`: **현재 켜져 있는 유지 기능**의 재검사를 요청합니다. 꺼진 기능을 켜거나, 연습 보상을 다시 지급하는 버튼이 아닙니다.
- 화면 전환·로딩·시즌/플레이오프/일본시리즈 전환으로 대상 확인이 안 되면 안전 대기할 수 있습니다. 화면 로딩이 끝난 뒤 상태를 확인하세요.
- 계속 대기하거나 엉뚱한 대상이 보이면 반복 적용하지 말고 대상 구단·선수와 오류 문구를 확인해 주세요.
- 패널을 숨기거나 다른 메뉴로 이동하는 것과 **기능 OFF는 다릅니다.** 멈추려면 해당 기능의 OFF 버튼을 사용합니다.

### 주소·선수 대상이 바뀌었을 때

스타플레이어 본인·현재 구단, 페넌트, 고시엔의 주소를 게임에서 다시 탐색합니다. 게임 업데이트가 없어도 같은 실행 중에 주소가 바뀌거나 접근할 수 없으면 현재 근거를 다시 확인합니다. 선택 선수는 ID·생년 정보·이름으로 같은 선수인지 대조하며, 다른 선수로 바뀌었거나 하나로 특정할 수 없으면 대기합니다.

1. 사용 모드의 세이브를 불러오고 명단 또는 메인 화면에 진입합니다.
2. 해당 화면의 명단 새로고침이나 패널의 `주소·이름 갱신`을 누릅니다.
3. 계속 찾지 못하면 호환성 영역의 `지금 다시 분석`으로 재탐색하고 `전체 보고서`를 확인합니다.
4. 선수가 사라졌거나 학교 구성이 바뀌었다면 대상을 다시 확인한 뒤 필요한 기능을 적용합니다.

고시엔의 비어 있는 부원 칸은 제외합니다. 완전 강화 패널은 기본 블록과 **동일한 전체 명단으로 확인된 복제본**을 함께 처리합니다. 복제본 수를 고정하지 않으며, 일부만 닮은 블록이나 다른 학교는 제외합니다. 개별 선수를 찾지 못했다고 전체 부원으로 적용 대상을 바꾸지 않습니다. 페넌트도 동일 구단·명단으로 확인된 복제본 탐색을 보강했고, 스타플레이어의 기존 동일 선수·구단 검증을 유지합니다.

분석 결과는 업데이트 진단 보고서에도 반영됩니다. 이 보고서는 다음 수정에 사용할 근거이며, 알 수 없는 새 게임 빌드의 모든 기능을 자동 허용하거나 외부 치트테이블과 동기화하는 기능은 아닙니다.

### F8 자동 감지와 F9 타이밍·정타 보정

경로: **공통 → 경기 조작 → 사용자 공수 자동 감지·전환**. 기존 수동 F6/F7은 그대로 사용할 수 있습니다.

| 그룹 | 자동 전환에 넣을 수 있는 기능 |
| --- | --- |
| F6 · 사용자 투구·수비 | 실전 투수 체력, 베스트 피치, 스트라이크 존, 두 번째 도착점, 수비 가속, 송구 가속 |
| F7 · 사용자 타격 | 베스트 히팅(컨택 어시스트), 스트라이크 존, 두 번째 도착점, 주루 가속 |

1. 수동 F6/F7이나 관련 개별 기능이 켜져 있다면 먼저 OFF합니다.
2. 각 그룹에서 `전체 선택` 또는 필요한 개별 항목만 체크합니다. 한쪽 그룹을 비워 두어도 되지만 양쪽 합쳐 하나 이상은 선택해야 합니다.
3. `선택 적용·자동 ON`을 누릅니다. 이후 **F8**로 마지막 적용한 구성을 ON/OFF합니다. 체크만 바꾼 미적용 내용은 F8에 반영되지 않습니다. 처음 F8을 누르면 수비 6개·공격 4개 기본 구성으로 시작하고 타이밍은 OFF입니다.
4. 사용자 팀의 공수가 확인되고 선택 기능 적용이 완료되면 전환음이 납니다. **수비는 짧게 1번, 공격은 빠르게 2번**입니다. 반복 감지나 실패에는 전환음이 나지 않습니다.
5. **F9**로 타이밍·정타 보정을 별도로 켜거나 끕니다. 자동 감지는 계속 유지되며, 수비 중 ON하면 사용자 타격까지 대기합니다. 타이밍을 OFF해도 자동 공격의 컨택 어시스트는 유지됩니다.
6. 끝낼 때는 F8 또는 `자동 OFF·원본 복구`를 누릅니다. 수동 F6/F7이나 F9 외의 관련 개별 기능을 조작하면 자동 전환이 먼저 종료됩니다.

F9는 기존 타이밍·정타·상황별 타구 보정 기능을 따로 제어합니다. 타구 계산, 현실성, 땅볼 기준은 그대로이며 자동 스윙이나 화면의 BEST 표시를 보장하지 않습니다. 자동 감지가 꺼져 있을 때 F9는 기존 수동 개별 기능입니다. **수동 F7은 타이밍을 포함한 기존 전체 묶음**을 유지합니다. 자동 감지를 다시 켜려면 수동 기능을 먼저 OFF하세요.

전환음과 카운트 확인음은 `활성화·비활성화 작동음` 설정을 따릅니다. F8/F9와 선택 구성은 Studio를 다시 실행하면 자동으로 켜지지 않습니다.

메뉴·리플레이·로딩·사용자 팀을 구분할 수 없는 상태에서는 자동 기능을 해제하고 대기합니다. 게임 연결이 끊기면 자동 전환이 종료되며, Studio 시작 시 자동으로 켜지지 않습니다. 일반 경기에서 양쪽 공수 판독을 대조했으며, 고시엔·페넌트·스타플레이어의 모든 경기 상황까지 검증한 것은 아닙니다.

**베스트 피치는 실제 처리 시 사용자 투수인지 추가 확인하고 CPU·미확인 대상은 보정하지 않습니다.** 두 번의 투구 입력은 직접 해야 합니다. 다른 항목은 공수 감지에 따라 묶음을 전환하는 방식이므로 모든 순간·모든 훅에 같은 사용자 판별이 들어간 것은 아닙니다. 구속·타구속도 프리셋과 볼카운트 등은 이 자동 전환 대상에 포함되지 않습니다.

## 6. 스타플레이어 휴일 동료 훈련

이 기능은 **선수교류 → 연습**에서 상대 선수가 얻는 성장을 조정합니다. 게임에서 해당 자유 행동·휴일 연습을 할 수 있어야 하며, 언제든 연습 이벤트를 강제로 여는 기능은 아닙니다.

### 대상 선택

1. `스타플레이어 → 동료 훈련`으로 이동합니다.
2. `1. 구단 선택`에서 상대 선수의 구단을 고릅니다.
3. `2. 선수 스캔`을 누릅니다.
4. 이름 검색 또는 `3. 연습 상대 선택`으로 선수를 고릅니다.
5. 아래에서 필요한 기능을 설정하고 **각 기능의 적용 버튼**을 누릅니다.
6. 각 항목의 `적용 대상`이 게임에서 함께 연습할 선수와 같은지 확인한 뒤 게임의 연습을 진행합니다.

상단에서 선수를 바꾸는 것만으로 이미 ON인 기능의 대상이 바뀌지는 않습니다. 상대를 바꿨다면 사용하는 기능마다 다시 적용하세요. 대상 선택은 공통으로 사용하지만 세 기능의 ON/OFF는 각각 관리합니다.

### 세 가지 조정 방식의 차이

| 기능 | 하는 일 | 예시 |
| --- | --- | --- |
| 능력 지정 | 원래 연습 보상으로 뽑힐 능력의 후보를 제한 | 파워·송구만 후보로 선택 |
| 상승량 배율 | 실제로 발생한 해당 능력의 자연 상승량에 배율 적용 | 원래 +5가 2배이면 +10 |
| 추가 보상 | 원래 연습 보상과 별도로 선택한 능력·특능 보상 지급 | 피로 회복 +2, 포수 리드 +1단계 |

**능력 지정**

- 선택한 후보가 매번 전부 오르는 것은 아닙니다. 게임의 원래 보상 개수보다 많이 골랐다면 그중 일부가 뽑힙니다.
- 같은 능력은 한 번의 연습에서 중복으로 뽑히지 않습니다.
- 야수와 투수는 적용되는 후보가 다릅니다. 다른 수비 포지션·피로 회복·세부 구종 항목 등은 추가 보상 메뉴를 확인하세요.
- 중단 버튼은 `능력 지정만 OFF`입니다.

**상승량 배율**

- 기존 능력치 전체를 곱하는 것이 아니라 **앞으로 연습에서 얻는 상승량**을 곱합니다.
- 체크하지 않은 항목은 원래 1배입니다. 0.01~100배 범위에서 소수 둘째 자리까지 입력할 수 있습니다.
- `입력칸에 채우기`는 입력값만 채웁니다. 마지막에 `설정 적용 · 계속 ON`을 눌러야 적용됩니다.
- 예: +5 × 2.5배는 반올림하여 +13. 최종 능력 상한 때문에 실제 증가가 작아질 수 있습니다.
- 현재 항목별 배율은 야수 능력 경로용입니다. 능력 지정 메뉴에 있는 투수 5종까지 전부 곱하는 기능은 아닙니다.

**추가 보상**

- 이 배포본에는 기본 능력, 수비·포수 리드, 투수·구종, 특수능력, 녹색 특능·성향, 탄도 등 **134개 조정 항목**이 있습니다. 분류와 검색을 이용하세요.
- `+숫자` 항목은 증가량, 등급형은 단계 증가, 보유형은 습득입니다. `→` 선택 항목은 선택한 종류로 바꾸는 방식이므로 반대 성향·약점 선택에 주의하세요.
- 체크와 값을 정한 뒤 `추가 보상 적용 · 계속 ON`을 누릅니다. 중단은 `추가 보상만 OFF`입니다.
- 원래 보상이 한 개 이상 발생하는 연습에서만 지급합니다. 상한, 선수 유형, 구종 보유 여부 등의 제한이 적용됩니다. 없는 구종을 새로 만드는 기능은 아닙니다.
- 포수 리드는 S, 등급형 특능은 A 상한입니다. 표시되는 입력 범위를 지켜 주세요.
- **추가 보상에는 상승량 배율을 다시 곱하지 않습니다.** 예를 들어 자연 보상 +5에 2배, 같은 능력 추가 보상 +3이면 상한 전 기준 +13입니다.
- 결과 대화창에는 원래 보상만 표시될 수 있습니다. 연습 후 선수의 **능력 상세 화면**에서 확인하세요.

세 기능 모두 OFF는 앞으로의 처리를 멈추는 의미입니다. **이미 얻은 능력치·특능은 OFF나 `원본 복구`로 되돌아가지 않습니다.** 되돌릴 필요가 있다면 미리 보관한 세이브 백업을 사용해야 합니다.

## 7. 옵션 저장과 불러오기

지원되는 기능의 `이 기능 설정 저장`을 펼치면 설정을 보관할 수 있습니다.

1. 체크 상태와 세부 입력값을 원하는 대로 맞춥니다.
2. 시작 시 동작을 `설정만 불러오기` 또는 `자동 ON 요청` 중에서 고릅니다.
3. `현재 입력 설정 저장`을 누릅니다.

- **저장 버튼을 누른 기능만** 불러옵니다. 모든 조작 내용이 무조건 자동 저장되는 방식은 아닙니다.
- `설정만 불러오기`는 입력값 복원입니다. 실제 적용과는 별개입니다.
- `자동 ON 요청`은 지원되는 기능에 한해 시작 시 한 번 요청하며, 게임·대상 확인을 통과해야 작동합니다. 모든 패널의 무조건 자동 실행을 뜻하지 않습니다.
- **동료 훈련처럼 대상 선수 지정이 필요한 기능은 재시작 후 현재 선수를 다시 선택하고 적용해야 합니다.** 예전 선수 주소를 그대로 재사용하지 않습니다.
- `저장값 다시 불러오기`로 보관한 입력값을 다시 불러올 수 있습니다.
- `저장 해제`는 저장 목록에서 지우는 동작입니다. 현재 ON인 기능은 별도로 OFF해 주세요.
- `저장 설정 → JSON 내보내기/JSON 가져오기`로 설정을 파일로 옮길 수 있습니다.
- 가져온 항목은 설정만 복원합니다. 자동 ON이 필요하면 각 기능에서 다시 선택해 저장하세요.

게임 세이브 백업과 Studio 설정 JSON은 서로 다릅니다. 설정 JSON만으로 변경 전 게임 능력치가 복원되지는 않습니다.

## 8. 종료와 버전 교체

1. 사용하는 기능의 OFF 버튼을 눌러 중단 상태를 확인합니다.
2. Studio 창의 닫기 버튼으로 **정상 종료**합니다.
3. 새 EXE로 교체할 때도 기존 Studio가 완전히 닫힌 뒤 진행합니다.

게임이 실행 중이고 기능이 켜져 있을 때 작업 관리자에서 Studio를 강제 종료하지 마세요. 프로그램 종료 시 수행되는 복구가 생략될 수 있습니다. 복구 오류가 표시되면 반복 적용하거나 무시하지 말고 오류 내용을 확인해 주세요.

업데이트 전 기존 EXE와 게임 세이브, 필요한 설정 JSON을 따로 보관하면 좋습니다. EXE를 이전 버전으로 돌리는 것만으로 게임 세이브의 변경까지 되돌아가지는 않습니다.

## 9. 자주 묻는 문제

### 실행이 안 되거나 .NET 설치 안내가 나와요

.NET **6 Desktop Runtime x64**가 설치되어 있는지 확인하세요. 다른 주 버전이나 x86만 설치된 상태로는 해결되지 않을 수 있습니다. 설치 후 다시 실행합니다.

### 창이 비어 있거나 WebView2 오류가 나와요

Microsoft 공식 WebView2 Runtime 설치 상태를 확인하세요. 임의의 DLL을 내려받아 게임 폴더에 넣는 방식은 권장하지 않습니다.

### `이미 실행 중`이라고 나와요

기존 폴더형 Studio 또는 단일 파일 Studio가 열려 있는지 확인하고 정상 종료합니다. 단일 EXE를 연속으로 여러 번 실행하지 마세요.

### 체크했는데 효과가 없어요

적용 버튼을 눌렀는지, 대상 구단·선수가 맞는지, 게임 모드와 화면 조건이 맞는지 확인하세요. 연습 기능은 해당 연습이 실제로 발생해야 합니다. 입력·저장·적용은 각각 다른 동작입니다.

<a id="compatibility-help"></a>

### 게임 업데이트 후 기능이 잠겼어요 / 네이티브 엔진 팩 분리라고 나와요

0.7.93부터 정상 지원, 기능별 부분 호환, 호환성 확인 필요 상태를 구분해서 안내합니다. `지금 다시 분석`을 실행하고 `전체 보고서`에서 기능별 결과를 확인하세요. 부분 호환 상태에서는 확인된 기능만 사용할 수 있고, 선수 구조·내장 패널이 확인되지 않았다면 그 항목은 계속 잠깁니다. 예전의 `네이티브 엔진 팩 분리` 문구만으로 모든 기능이 사용 가능하거나 전부 고장났다고 판단하지 마세요. 재설치나 관리자 권한으로 호환 검사를 대신할 수는 없습니다.

<a id="translation-support"></a>

### 한글패치를 했는데 사용할 수 있나요?

0.7.94는 **기준 게임 2.2.0에서 검토된 선수 이름 문자열·표시값만 변경한 실행파일**을 별도로 검사합니다. 이름이 바뀌어 전체 파일 해시가 달라도 나머지 코드·선수 ID·주소 구조·데이터가 기준과 같은지 확인한 뒤 지원합니다. 단순히 이름이 한글이라는 이유로 차단하거나, 버전 숫자만 같다고 허용하지 않습니다.

공개된 [제작자의 한글패치 v1.3 안내](https://gall.dcinside.com/mgallery/board/view/?id=prospi2019&no=14298)와 변경 코드를 검토했습니다. **모든 한글패치·로스터 모드 지원을 뜻하지 않습니다.** 학교 데이터를 덧붙이거나 코드·구조·그 밖의 데이터를 바꾸는 패치는 별도 검증이 필요합니다. 실제 제보자의 패치 버전과 게임 내 결과는 아직 확인하지 못했습니다. 패치 파일을 자동 다운로드·설치하거나 게임 EXE를 수정하는 기능은 없습니다.

잠긴다면 패치를 무조건 지우기 전에 Studio/게임 버전, 패치 이름·버전, 호환성 상태와 보고서의 오류를 알려주세요. 원본 게임 파일이나 패치 EXE 전체를 공개 첨부할 필요는 없습니다.

### 옵션·카메라 패널에서 ASSERT 불일치가 나요

## 15. 전 모드 유저 옵션·카메라 — 58항목

경로: 공통 → 카메라·옵션 → 패널 열기. **0.7.93에서 게임 2.2.0의 옵션 처리에 맞추고, 58항목의 실제 선택 목록을 복구했습니다. 0.7.94에도 포함됩니다.** 이전 2.1.0 패널의 ASSERT 불일치와 빈 선택지 문제를 수정했습니다. 패널 이름에 예전 버전 문구가 남아 있어도 이 배포본은 Studio의 보정된 경로를 사용합니다.

패널을 열거나 분류를 바꾸기만 해서는 선택값이 적용되지 않습니다. 원하는 항목을 선택하면 이후 게임 옵션 구성 시 반영됩니다. **게임 설정 유지**는 다음 장면부터 그 항목을 강제하지 않는 선택입니다. OFF는 처리 개입을 멈추며 이미 열린 장면의 옵션을 즉시 되감지 않으므로, 게임 설정 확인이나 장면 재진입이 필요할 수 있습니다.

아래는 현재 패널의 선택지를 함께 정리한 표입니다. 모든 항목에 공통으로 있는 0번 게임 설정 유지와 내부 저장값 표시는 표에서 생략했습니다. 선택 번호는 메모리 원값이 아닙니다. 숨은 카메라·미확인·고신뢰 추론 항목은 모든 모드 실기 검증 완료가 아니며, 같은 필드를 공유하는 옵션은 일부 선택이 우선할 수 있습니다.
