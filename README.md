## 0.7.450 - 유니폼 같은 구단 모두 · 감독 오더 그대로 부상 예외

게임 2.3.0용입니다. 0.7.449 다음 변경(0.7.450)입니다. [자세한 내용](USER_GUIDE_0_7_450.ko.md#345-유니폼-같은-구단-모두--감독-오더-그대로-부상-예외-07450) (345장)

- **유니폼 지정 ‘같은 구단 모두’ (갤러리 댓글)**: DIRECT 선수 화면의 ‘경기·선수 보기에서도 이 유니폼 (LAB)’에서 팀에디트 디자인을 고른 뒤 ‘같은 구단 N명 모두’를 누르면, DIRECT 목록에서 그 선수와 같은 구단인 선수 모두(그 선수 포함)에게 같은 디자인이 지정됩니다. 스타플레이어에서 팀원들에게 한꺼번에 에디트 팀 유니폼을 입힐 때 쓰세요(스타 리그 구조를 불러와 팀원 한 명을 고른 뒤 누르면 됩니다). ‘같은 구단 모두 빼기’로 한꺼번에 뺄 수 있고, 한 명씩 지정하는 방법은 그대로입니다.
- **감독 오더 그대로 (LAB) 부상 예외 (갤러리 댓글)**: 스타 부상 실험 LAB으로 우리 팀 선수에게 부상을 주면, 감독 오더 그대로 LAB이 그 선수를 다시 선발로 세우던 문제를 고쳤습니다. 이제 부상 중인 선수 자리에는 게임이 그날 그 포지션에 넣은 선수를 그대로 둡니다. 부상 선수가 없으면 예전과 같습니다.

예전과 달라지는 점(0.7.449 대비): 유니폼 지정에 ‘같은 구단 모두’ 버튼 두 개가 더해졌습니다. 감독 오더 그대로 LAB이 부상 선수를 선발로 다시 세우지 않습니다(부상 선수가 없으면 같음). 다른 기능은 0.7.449와 같습니다.

문제 제보는 [GitHub 이슈](https://github.com/PrimeTimerer/ProspiStudio/issues)에 화면 캡처, Studio 버전, 로그와 함께 올려 주세요(자세한 방법은 아래 [문제 제보](#문제-제보)). 0.7.406~0.7.417도 화면 캡처, Studio 버전, 재현 순서가 정확히 적힌 GitHub 이슈(#15, #16, #18, #19, #20, #21, #25)와 캡처를 붙인 갤러리 글 덕분에 바로 원인을 찾아 고쳤고(0.7.414는 제보와 함께 올려 주신 세이브, 0.7.416은 오류 창 캡처로 확인), 0.7.410·0.7.412·0.7.415·0.7.417의 새 기능도 GitHub 이슈(#17, #19, #21, #24) 건의로 만들었습니다.

4. Studio에서 게임 인식과 호환성 상태를 확인하고, 쓸 기능의 **적용 또는 ON**을 누릅니다. 체크나 입력만으로는 적용되지 않는 항목이 있습니다.
5. 끝낼 때는 **모든 기능 OFF** 뒤 창의 닫기 버튼으로 정상 종료합니다. 기능이 켜진 채 작업 관리자로 강제 종료하지 마세요.

## 문제 제보

Studio와 CT 둘 다 수만 줄 규모의 큰 프로그램이라, 실제 로그와 화면 캡처 없이 설명만으로는 문제를 찾아 고치기가 거의 불가능합니다.

- 문제는 [GitHub 이슈](https://github.com/PrimeTimerer/ProspiStudio/issues)에 올려 주세요. 갤러리 댓글로 주신 제보·요청에는 대응하지 않습니다. 갤러리라면 최소한 따로 글을 쓰고 아래 자료를 모두 붙여 주셔야 확인할 수 있습니다.
- 함께 올릴 것: Studio 버전, 게임 모드와 상황(경기 중인지 메뉴인지 등), 켠 기능(카드·LAB 이름과 설정), 문제가 생기기까지의 순서, 화면 캡처(Studio 화면과 게임 화면), 로그 파일, 게임이 튕겼다면 크래시 파일
- 로그: `%LOCALAPPDATA%\Prospi26Studio\logs` 폴더의 최근 파일(빅리그식 조작 시스템의 ‘로그 폴더’ 버튼으로도 열립니다)
- 크래시 파일: `%LOCALAPPDATA%\prospi\Saved\Crashes`에서 가장 최근 폴더를 통째로 압축(UE4Minidump.dmp 포함)

```text
Studio 버전:
게임 버전:
한글패치·로스터 모드 이름과 버전: (없으면 없음)
호환성 상태 / 보고서의 오류:
모드 및 화면: (예: 스타플레이어 / 일본시리즈 경기 전)
기능 이름:
대상 구단·선수:
```
