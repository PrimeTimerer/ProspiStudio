## 바뀐 것 (0.7.398)

- **선택 목록 위치 수정 (0.7.398)**: 4K 등 화면 배율이 큰 모니터에서 선택 상자의 목록이 엉뚱한 곳에 뜨고, 창을 최대화하거나 Ctrl+휠로 확대하면 화면 밖으로 나가던 문제를 고쳤습니다. 이제 목록을 Studio 화면 안에서 그려서 선택 상자 바로 아래(아래 공간이 없으면 바로 위)에 뜨고, 긴 목록은 창 안에서 스크롤됩니다(GitHub 이슈 #14).

예전과 달라지는 점(0.7.397 대비): 선택 상자의 목록이 윈도우 기본 목록 대신 Studio 화면 안에 그려져 선택 상자 바로 아래(공간이 없으면 바로 위)에 뜹니다. WebView2가 오래된 PC에서는 이전과 같습니다.

## 아직 확인 중인 것
