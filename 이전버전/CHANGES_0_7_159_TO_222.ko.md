모션 LAB은 보기와 화면 안 미리보기 전용입니다. 뼈대 연결은 추정이며 게임 적용은 다음 단계입니다. 다른 패치 실행 파일의 인정은 게임 코드가 순정과 같은 경우에만 해당하고, 코드·구조를 바꾼 패치나 업데이트된 게임은 관대 호환 모드를 직접 켜야 합니다. 관대 호환 모드는 한 번 켜면 다음 실행에도 켜진 채로 시작하므로, 필요 없으면 버튼으로 끄세요.

## 0.7.209~211에서 새로 사용할 때

번호키는 Ctrl을 누르면 양 팀, 별도 내 팀 전체 옵션을 켜면 내 팀 선수 전체에 적용합니다. 두 범위는 사용자가 직접 선택하며 F6·F7·F8과 속도 3종의 기존 적용 범위를 임의로 제한하거나 바꾸지 않았습니다. 드래프트의 게임 목록은 새 보기이고 저장된 전체 후보 목록은 계속 기본입니다. 전술 경기의 지도·메시지·등장 연출은 해당 LAB의 선택 사항으로 예전 표시·연출을 되찾을 수 있습니다.

새 특능·오리변 가져오기는 원본을 고른 뒤 항목별 미리보기·적용·직전 되돌리기를 제공합니다. 0.7.211은 한 번의 적용에서 같은 방향 오리변 두 개가 첫 빈 칸을 동시에 가리켜 둘째가 건너뛰어지던 결함만 바로잡았습니다. 0.7.209~210의 게임 안 실제 표시와 저장 후 재접속은 별도 확인이 필요합니다. 관대 호환 모드는 검토되지 않은 실행파일에서만 직접 켜며 위험을 알리는 선택 기능입니다. 자동 검사 통과가 바뀐 게임의 구조·안정성 검증은 아닙니다.

## 0.7.206에서 달라진 표시

우투 기준 슬라이더계 왼쪽·커브계 왼쪽 아래·포크계 아래·싱커계 오른쪽 아래·슈트계 오른쪽이고 좌투는 좌우 반전입니다. 직구계는 막대가 없습니다. 6은 다섯 칸, 7(S)은 화살촉까지, 7보다 큰 값은 가득 찬 S+로 그립니다. 이전보다 채워진 칸이 하나 적게 보여도 실제 변화량을 낮춘 것은 아닙니다.

능력 카드 배치와 숫자 편집·명령·값·계산은 유지합니다. 스피리츠 UI 기본 OFF도 그대로입니다. 0.7.206의 표시 변경만으로 0.7.205의 자연 경기 검증 대기가 해소된 것은 아닙니다.

## 0.7.205에서 바뀌어 현재도 유지되는 방향과 기본값

인스턴트의 이전 오리지널 직접 계수는 좌투의 좌우 반전이 적용되지 않았고 종 +가 위였습니다. 0.7.205는 횡 +가 슬라이더 쪽, 횡 −가 슈트 쪽이며 종 +가 아래, 종 −가 위입니다. 이전 값을 그대로 옮기지 말고 투타와 방향을 확인하세요. 오리지널의 구질·변화 직접 설정이 방향을 함께 덮어쓰지 않으며 별도 변화 방향은 처음 연결할 때 원본 유지입니다.

제구도 기본 원본 유지입니다. 자동 감지는 기본 OFF로 기존 수동 연결을 유지하며, ON일 때만 마운드의 사용자 투수를 따라갑니다. 되돌아온 투수는 같은 Studio 실행·같은 12구종 구성일 때 보관한 설정을 되찾고 새 투수는 새로 연결합니다. 인스턴트 OFF·모든 기능 OFF는 감지를 끝내며 게임 재시작 때 보관 투수는 초기화합니다.

DIRECT 오리지널 기록 횡 +는 베이스 구종의 방향에 더하는 값입니다. 싱커·슈트·투심 베이스에서는 슈트 쪽으로 더하므로 인스턴트 최종 방향의 +와 다릅니다. DIRECT의 저장값·쓰기는 유지하고 안내를 고쳤습니다. 기존 구속·구위·헛스윙·변화량·예리함, F6·F7·F8·번호키·선수 선택·속도 기능의 범위와 CT는 바꾸지 않았습니다.

제구는 경기 중 계산값 조정이며 기본 능력 저장 편집이 아닙니다. 베스트 피칭 ON에서는 사용자 릴리스의 제구 차이가 가려질 수 있습니다. 방향 그림·cm·존 안내는 추정치이고 실제 궤적·스트라이크 보장이 아닙니다. 좌투 궤적·교체 후 설정 복귀·제구 체감 등 자연 경기 검증은 남아 있습니다.

## 현재도 구분해야 할 범위

- 수비·송구 속도는 기존 범위로 사용합니다. 공통 선수 선택이 모든 속도와 모든 기능을 자동으로 선수별 제한하는 것은 아닙니다. 주루는 별도 선택 옵션으로 제한할 수 있습니다.
- 전술 경기 LAB, 회색 메뉴 지원, 자동 경기로 끝까지, 난입 요청은 서로 다른 기능입니다. 필요한 것을 함께 사용할 수 있지만, 상황상 불가능한 교체나 기록 없는 리플레이를 만들어 내지는 않습니다.
- 사진 유사도는 얼굴 기하 지표입니다. 사진과 동일한 인물·질감·표정을 보장하지 않습니다.
- 성장·능력·자원을 이미 바꾼 뒤 OFF하더라도 값은 되돌아가지 않을 수 있습니다. 게임 세이브 백업이 별도로 필요합니다.
- 세이브 편집의 원본 저장은 Studio가 백업과 확인을 하지만, 게임이 편집된 세이브를 불러오는 확인은 아직입니다. 별도 복사본을 먼저 두세요.
- 세이브 편집의 특능·오리변 가져오기는 게임 실행 파일·Original.dat을 읽기만 하며, 고른 뒤 그 파일이 바뀌면 다시 고르게 합니다.
- 통합 상황실의 자동 유지와 원래 통합 패널은 같은 칸을 두 곳에서 유지하지 않도록 함께 켤 수 없습니다. 관전 모드·빠른 진행·다음 내 차례까지 건너뛰기는 서로 다른 기능이며, 건너뛰기를 누르면 내 차례까지는 건너뛰기가 우선합니다.
- 드래프트의 내 후보는 Studio 파일에 저장한 데이터이며 게임의 후보 목록·지명과는 별개입니다. 저장한 능력은 저장할 때의 값이고 성장 예측이 아닙니다.
- 투구 자동 (수비는 직접)이 켜져 있으면 내 투수에게 거는 기능은 CPU가 던지는 공에 작동하지 않고, 투구 중 견제·도루 송구도 CPU가 합니다.
- 자동 테스트와 패키지·복원 검증을 통과했으나, 모든 모드·대회·시즌의 실제 경기와 저장 후 재접속까지 검증 완료한 것은 아닙니다.
