## 바뀐 것 (0.7.412~0.7.413)

- **PCI 타격에도 스윙 타이밍 표시 (0.7.413)**: 빅리그식 타격을 PCI(배트 커서)로 칠 때도 스윙마다 게임 화면 위쪽 가운데에 타이밍(완벽·좋음·조금 이름/늦음·이름/늦음·아주 이름/늦음)이 2.5초 작게 뜹니다. 예전에는 클래식에서만 떴습니다. 완벽은 PCI 타격의 완벽 타이밍 구간 안일 때만 뜹니다. 타격 탭의 ‘스윙 타이밍 표시’ 체크(기본 켜짐)가 이제 PCI에서도 보이며, 끄면 뜨지 않습니다. 게임은 테두리 없는 창이어야 보입니다.
- **무조건 파울을 일반 타격에도 (0.7.412, GitHub #19 건의)**: 빅리그식 조작 시스템 › 타격의 ‘무조건 파울’에서 범위를 고르면 그 아래에 ‘무조건 파울을 일반 타격에도’ 체크가 보입니다(기본 꺼짐). 켜면 빅리그식 타격을 끄고 스피리츠 일반 타격(존 타격·커서 타격)으로 칠 때도, 고른 범위(내 타석·CPU 타석·모두)에서 맞힌 공이 포수 뒤 그물이나 홈플레이트 뒤 땅으로 가는 파울이 되어 타석이 이어집니다. 맞음·헛스윙은 게임 판정 그대로이고 헛스윙은 그대로 헛스윙입니다. 여기서 ‘내 타석’은 게임이 내 팀 공격이라고 알려 주는 타석이라 패드·키보드 모두 됩니다. 빅리그식 타격을 켜면 예전처럼 빅리그식 방식으로 작동합니다.

예전과 달라지는 점(0.7.411 대비): 0.7.412의 ‘무조건 파울을 일반 타격에도’는 새 체크이고 기본 꺼짐이라, 켜기 전에는 예전과 같습니다. 0.7.413부터 빅리그식 타격을 PCI로 쓰고 ‘스윙 타이밍 표시’가 켜져 있으면(기본) PCI 스윙 뒤에도 타이밍이 뜹니다. 끄면 예전처럼 뜨지 않습니다. 클래식의 타이밍 표시와 타구·판정은 그대로입니다.

## 문제 제보 방식 (0.7.405부터)

- Studio와 CT 둘 다 수만 줄 규모의 큰 프로그램이 되어, 실제 로그와 화면 캡처 없이 설명만으로는 문제를 찾아 고치기가 거의 불가능합니다.
- 그래서 갤러리 댓글로 주신 제보·요청에는 대응하지 않습니다. 문제는 [GitHub 이슈](https://github.com/PrimeTimerer/ProspiStudio/issues)에 올려 주세요. 갤러리라면 최소한 따로 글을 쓰고 아래 자료를 모두 붙여 주셔야 확인할 수 있습니다.
- 함께 올릴 것: Studio 버전, 게임 모드와 상황(경기 중인지 메뉴인지 등), 켠 기능(카드·LAB 이름과 설정), 문제가 생기기까지의 순서, 화면 캡처(Studio 화면과 게임 화면), 로그 파일, 게임이 튕겼다면 크래시 파일
- 로그: `%LOCALAPPDATA%\Prospi26Studio\logs` 폴더의 최근 파일(빅리그식 조작 시스템의 ‘로그 폴더’ 버튼으로도 열립니다)
- 크래시 파일: `%LOCALAPPDATA%\prospi\Saved\Crashes`에서 가장 최근 폴더를 통째로 압축(UE4Minidump.dmp 포함)
- 0.7.406~0.7.411도 화면 캡처, Studio 버전, 재현 순서가 정확히 적힌 GitHub 이슈(#15, #16, #18, #19, #20) 덕분에 바로 원인을 찾아 고쳤고, 0.7.410·0.7.412의 새 기능도 GitHub 이슈(#17, #19) 건의로 만들었습니다.

## 아직 확인 중인 것

- PCI 타격 스윙 타이밍 표시: 경기에서 PCI 스윙 뒤 게임 화면 위쪽에 타이밍이 뜨는지
- 무조건 파울을 일반 타격에도: 빅리그식 타격을 끈 경기에서 고른 범위의 맞힌 공이 파울로 돌아가 타석이 이어지고, 헛스윙은 그대로인지(건의해 주신 분의 확인 대기)
- 코드 패치 전 스레드 오류(#18): 제보해 주신 PC에서 기능이 켜지고 꺼지는지(제보해 주신 분의 확인 대기)
- 무조건 파울(#19): 고른 값이 유지되고, 고른 타석(내 타석, ‘CPU 타자 포함’의 CPU 타석)에서 맞힌 공이 파울로 돌아가 타석이 이어지는지
- 선수 가져오기(#20): 팀 공유로 받은 선수가 검색되고 외모·폼·음성이 들어가는지, 저장 뒤 게임에서 불러오기(제보해 주신 분의 확인 대기)
- 후보 이름 한국식으로: 게임의 드래프트 후보 목록(다시 연 뒤), 지명된 신인의 선수단 이름, 저장 뒤 다시 불러오기(건의해 주신 분의 확인 대기)
- 선발 등판일에 멈추기: 고른 투수의 선발일 아침에 스킵 종료 확인 창이 뜨고 끝내기를 고르면 그날 메뉴에서 멈추는지, 다른 투수의 선발일에는 그대로 넘어가는지, 포스트시즌(클라이맥스 시리즈·일본시리즈)
- 연봉 상한 바꾸기(0.7.408): 상한을 올린 스타의 연봉 협상에서 1차 미팅 보류 뒤 2차 미팅이 꺼지지 않고 진행되는지(제보해 주신 분의 확인 대기)
- 스타 트레이드: 신청한 선수가 다음 날 시작 때 우리 구단으로 옮겨지는지, 게임 트레이드 소식과 그날 오더, 저장 뒤 다시 불러오기, 게임 규칙에 걸린 신청의 안내
- 자동 업데이트: 0.7.411에서 이번 버전으로의 실제 업데이트
