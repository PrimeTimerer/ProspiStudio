## 바뀐 것

- **특능 효과 수치** (LAB, 0.7.260, 기본 꺼짐): 특능이 경기에서 더하는 값을 바꿉니다. 자동 진행의 안타·홈런 확률, 투수의 투구 7칸(제구·구위·변화·구속·구위 배율·구속 배율·체력), 타석의 콘택트·파워·번트, 주루·타구·수비 수치를 고칩니다. 우리 팀에만 적용하고, 범위는 고시엔·스타 경기 또는 모든 오프라인 모드입니다. 바꾸지 않은 항목은 게임 값 그대로이고 끄면 원래대로 돌아갑니다(공통 기능 › 개별 코드 훅, 기능 찾기 Ctrl+K ‘특능 효과’).
- **특능 편집 탭 넓어짐** (0.7.262): 스타·페넌트의 특능 편집 탭 위쪽에 특능 효과 켜기/끄기와 범위, ‘모든 특능 항상 발동’이 생겼습니다. ‘게임에서 얻을 수 없는 특능도 쓰기’(기본 꺼짐)를 켜면 고질라처럼 실제 선수가 가질 수 없는 특능과 값도 고를 수 있습니다. 특능마다 ‘효과’ 버튼으로 항상 발동(상황 조건 없이 늘 발동), 그 특능의 게임 효과 값, 추가 효과(타석 콘택트·파워, 투구 7칸, 자동 진행 타자·투수)를 정합니다. 예를 들어 타자 특능인 고질라에 투구 추가 효과를 주면 그 선수가 던질 때도 작동합니다.
- **레어 특능 편집** (LAB, 0.7.263~0.7.265, 기본 꺼짐): 레어 특능이 원래 하지 않는 효과를 더합니다. 지금은 고질라: 고질라를 가진 타자가 강진으로 밀어칠 때 광각 효과(감점 면제·방향 계수)를 받습니다. 당겨칠 때의 풀 히터 효과는 그대로, 직접 타격에만, 양 팀 모든 고질라 타자에게 적용합니다. 범위는 고시엔·스타 경기 또는 모든 오프라인 모드입니다(특능 편집 › 고질라 › 효과, 공통 기능 › 개별 코드 훅).
- **스타 연습 강화** (LAB, 0.7.261, 기본 꺼짐): 스타플레이어 연습마다 오르는 양을 기본 대비 N배(1.5~100배)로 바꿉니다. 고른 연습은 장비가 있을 때의 양(×1.5)을 기준으로 계산하고, 고르지 않은 연습은 게임 그대로입니다. 스타 훈련 옵션의 하루 훈련 배율과 함께 곱해집니다. 연습 메뉴에 보이는 양은 게임 원래 값이고 실제로 오르는 양이 N배입니다(스타플레이어 › 선수 성장).
- **유니폼 (구단)** (0.7.264~0.7.266): 게임은 선수마다 선수 기록 안의 ‘유니폼 구단’ 값으로 유니폼을 고릅니다. 올스타팀이 선수마다 다른 유니폼을 입는 것도 이 값이 선수마다 다르기 때문입니다. 12개 구단 또는 에디트 팀 디자인(그 선수가 들어 있는 팀에디트 팀의 디자인)을 고를 수 있습니다.
- **유니폼 바꾸는 곳**: 게임을 켠 채로는 DIRECT 선수 편집에서 편집할 수 있는 모든 선수(페넌트·스타·고시엔·선수 데이터 커스텀 등)의 기본·수비·성장 탭 ‘유니폼 (구단)’, 게임을 끈 상태에서는 세이브 편집의 신상 탭(에디트 선수 파일에는 직접 만든 선수와 팀에디트 팀 선수가 모두 나옵니다). 처음 읽은 값은 ‘원래 값’으로 되돌릴 수 있습니다.
- **이름 보기 안내** (0.7.264): 이름표를 읽지 못한 이유가 스위치 아래에 잘리지 않고 다 보입니다. 영어·한글 보기는 Studio 화면만 바꾸고(게임 화면은 그대로), 이름이 한자·가나로 저장된 선수만 바뀐다는 안내를 넣었습니다(한글 패치로 만든 세이브의 한글 이름은 그대로).

예전과 달라지는 점: 특능 효과 수치·스타 연습 강화·레어 특능 편집은 켜야 동작하는 새 LAB입니다(기본 꺼짐). 특능 편집 탭은 추가만 있고 ‘게임에서 얻을 수 없는 특능도 쓰기’를 끄면 예전 버튼 그대로입니다. 공통 기능의 특능 효과 수치 카드에서 저장해도 항상 발동·추가 효과 설정이 지워지지 않습니다. DIRECT와 세이브 편집에 ‘유니폼 (구단)’ 칸이 새로 생겼고, 이름 보기 오류 문구가 한 줄 아래에 전부 보입니다. 그 밖의 기능은 0.7.259와 같습니다.

## 아직 확인 중인 것

- 특능 효과 수치·항상 발동·추가 효과가 경기에서 뜻대로 작동하는지(타자 특능을 가진 선수가 던질 때 포함)
- 스타 연습 강화의 배율만큼 실제로 오르는지(스타 훈련 옵션과 함께 켰을 때 포함)
- 레어 특능 편집(고질라 광각)이 강진으로 밀어칠 때 적용되는지
- 유니폼 (구단)을 바꾼 선수가 선수 데이터와 실제 경기에서 바뀐 유니폼을 입는지, 어느 팀에도 없는 선수에게 에디트 팀 디자인을 골랐을 때 어떤 디자인이 나오는지
