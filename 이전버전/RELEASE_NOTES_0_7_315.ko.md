## 바뀐 것 (0.7.314~0.7.315)

- **원본 수정 허용 (0.7.315)**: DIRECT 선수 편집의 선수 데이터 팀별·OB·커스텀에서 게임 내장 선수 원본(현역 12구단·OB·국가대표·WBC 일본)을 직접 편집할 수 있습니다. 원본 선수를 고르면 나오는 안내의 ‘원본 수정 허용’을 누르고 안내에 동의해야 켜집니다(기본 꺼짐 = 예전처럼 읽기 전용). 켜져 있는 동안 능력·특능·이름·외모·가져오기 같은 기존 편집 기능이 원본에 그대로 쓰입니다. 원본은 게임을 끄면 원래대로 돌아가므로 Studio가 바꾼 값을 기억했다가 게임을 켤 때마다 다시 넣고, 게임 업데이트로 그 선수 데이터가 바뀌었으면 덮어쓰지 않고 건너뛴 뒤 알려 줍니다. ‘이 선수 원본으로 되돌리기’와 ‘모두 되돌리기’로 게임 원래 값으로 돌릴 수 있습니다(꺼진 상태에서도 됩니다). 이미 만든 세이브의 선수는 바뀌지 않고, 원본을 읽어 새로 만드는 팀·경기에 반영되는 구조입니다. **원본 수정은 사용자 책임입니다. 선수 데이터 업데이트와 맞지 않는 문제, 게임 밸런스 변화 등 원본 수정으로 생기는 일은 제작자가 책임지지 않습니다.**
- **타격 방향 · 밀어치기·당겨치기 (새 LAB, 0.7.314)**: 게임은 스윙 타이밍을 1/60초(한 프레임) 단위로만 봅니다. 정타 프레임에 맞으면 늘 같은 쪽으로 10~15°, 한 프레임 빠르거나 늦어도 10~15°만 틀어져 대부분 가운데로 가고, 밀어치려면 두 프레임 이상 늦어야 해서 그만큼 타구가 약해집니다. 공통 기능 › 경기 조작의 새 항목을 켜면 정타가 아닌 타구의 좌우 각도에 ‘방향 폭’(×1.0~×3.0, 기본 ×2.0)을 곱해 한 프레임 차이로도 당겨치기·밀어치기가 됩니다(넓히는 각도는 42°까지, 게임이 원래 더 크게 낸 각도는 그대로). ‘정타 가운데 중심’을 켜면 정타 타구가 한쪽 대신 가운데 양쪽으로 고르게 갑니다. 기본은 내가 치는 타석만이고 ‘CPU 타자에도’를 켜면 CPU 타구도 바뀝니다. 타구 속도는 바꾸지 않습니다. 카드에 마지막 타구의 타이밍과 게임 각도 → 바뀐 각도, 내 타격·CPU 타구 수가 나옵니다. 완벽 타이밍(F7)·특능 효과 수치와 함께 켤 수 있습니다. 기본 꺼짐.

예전과 달라지는 점: 두 기능 모두 기본 꺼짐이라 켜지 않으면 0.7.313과 같습니다. 원본 선수의 읽기 전용 안내에 ‘원본 수정 허용’ 버튼과 책임 안내가 추가됐습니다.

## 아직 확인 중인 것

- 타격 방향: 한 프레임 빠르거나 늦은 타구가 좌·우로 가는지, 정타 타구의 좌우 분포, CPU 타구가 어느 경로로 계산되는지
- 원본 수정: 바꾼 국가대표·WBC·현역 원본이 어느 경기·화면에 바로 반영되는지, 게임을 다시 켠 뒤 다시 적용 보고
