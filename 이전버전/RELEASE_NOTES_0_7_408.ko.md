## 바뀐 것 (0.7.408)

- **연봉 상한 바꾸기 2차 미팅 튕김 수정 (0.7.408)**: ‘연봉 상한 바꾸기 (LAB)’로 상한을 올린 뒤 연봉이 약 25억엔을 넘는 스타의 연봉 협상에서 1차 미팅을 보류하고 2차 미팅에 들어가면 게임이 꺼지던 문제를 고쳤습니다(GitHub 이슈 #16 제보). 2차 미팅에서 구단이 다시 제시할 금액 후보를 고르는 게임 계산이 원래 상한 20억엔에 맞춘 크기라, 그보다 훨씬 큰 연봉에서는 넘쳐서 게임이 바로 꺼졌습니다(이 경우 크래시 파일도 남지 않습니다). 이제 LAB을 켜 두면 후보 수를 게임이 감당하는 크기로 묶어 2차 미팅이 그대로 진행됩니다. 따로 켤 것은 없습니다.

예전과 달라지는 점(0.7.407 대비): ‘연봉 상한 바꾸기 (LAB)’를 켰을 때 약 25억엔이 넘는 연봉의 2차 미팅에서 구단이 다시 제시하는 인상 폭이 1,000만엔 단위로 최대 6억 2천만엔(그 밖에 원래 인상률 그대로 한 가지와 인상 없음) 안에서 정해집니다. 20억엔 이하 연봉의 협상과 LAB을 끈 상태는 0.7.407과 같습니다.

## 문제 제보 방식 (0.7.405부터)

- Studio와 CT 둘 다 수만 줄 규모의 큰 프로그램이 되어, 실제 로그와 화면 캡처 없이 설명만으로는 문제를 찾아 고치기가 거의 불가능합니다.
- 그래서 갤러리 댓글로 주신 제보·요청에는 대응하지 않습니다. 문제는 [GitHub 이슈](https://github.com/PrimeTimerer/ProspiStudio/issues)에 올려 주세요. 갤러리라면 최소한 따로 글을 쓰고 아래 자료를 모두 붙여 주셔야 확인할 수 있습니다.
- 함께 올릴 것: Studio 버전, 게임 모드와 상황(경기 중인지 메뉴인지 등), 켠 기능(카드·LAB 이름과 설정), 문제가 생기기까지의 순서, 화면 캡처(Studio 화면과 게임 화면), 로그 파일, 게임이 튕겼다면 크래시 파일
- 로그: `%LOCALAPPDATA%\Prospi26Studio\logs` 폴더의 최근 파일(빅리그식 조작 시스템의 ‘로그 폴더’ 버튼으로도 열립니다)
- 크래시 파일: `%LOCALAPPDATA%\prospi\Saved\Crashes`에서 가장 최근 폴더를 통째로 압축(UE4Minidump.dmp 포함)
- 0.7.406~0.7.408도 화면 캡처, Studio 버전, 재현 순서가 정확히 적힌 GitHub 이슈(#15, #16) 덕분에 바로 원인을 찾아 고쳤습니다.

## 아직 확인 중인 것

- 연봉 상한 바꾸기: 상한을 올린 스타의 연봉 협상에서 1차 미팅 보류 뒤 2차 미팅이 꺼지지 않고 진행되는지(제보해 주신 분의 확인 대기)
- 기록의 올스타 화면(0.7.407): ‘올스타전에도 센트럴 DH 부문’을 켠 시즌에 뽑힌 센트럴 지명타자가 기록의 올스타 화면 지명타자 칸에 나오는지(페넌트·스타)
- 베스트 나인 화면(0.7.406): 페넌트에서 센트럴 지명타자 수상자가 지명타자 칸에 나오는지(스타는 제보해 주신 분이 확인)
- 무조건 파울: 내 타석과 ‘CPU 타자 포함’의 CPU 타석에서 맞힌 공이 파울로 돌아가 타석이 이어지는지
- 스타 트레이드: 신청한 선수가 다음 날 시작 때 우리 구단으로 옮겨지는지, 게임 트레이드 소식과 그날 오더, 저장 뒤 다시 불러오기, 게임 규칙에 걸린 신청의 안내
- 매트릭스를 켠 상태의 빅리그식 타격 파울팁이 파울로 남는지
- 투구 게이지를 끄고 빅리그식 타격만 켠 경기, 투구 게이지만 켜고 타격 탭을 끈 경기
- 자동 업데이트: 0.7.407에서 이번 버전으로의 실제 업데이트
