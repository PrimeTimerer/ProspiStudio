# PROSPI 26 Studio 0.7.224

직전 공개판 0.7.223의 동작을 유지하면서, 스타 레벨 조회와 NPB 참고 세이버메트릭스를 추가했습니다.

## 추가된 기능

- **스타 레벨 읽기:** 세이브 편집의 스타 저장 슬롯에서 실적·인기·교류·자산, 총점·레벨·다음 레벨까지의 점수를 조회합니다. 레벨·업적·보상을 편집하지 않습니다.
- **wOBA·wRAA·wRC·wRC+·간이 타자 WAR:** DIRECT의 시즌 기록·OPS와 세이브 선수 기록에 접힌 계산기를 추가했습니다. 기존 AVG·OBP·SLG·OPS·ISO·BB%·HR%·ERA·K/9도 그대로 있습니다.
- **NPB 기본값:** 2025 공식 리그 기록과 2023~2025 일본 12개 홈구장 보정을 조사해 넣었습니다. 구단과 주 포지션에 맞춰 기본 선택하며 직접 바꿀 수 있습니다. 실행할 때 웹 연결은 필요 없습니다.
- **주루·포지션 보정:** 게임 도루 수로 도루 기여(wSB), 포지션과 출장량으로 포지션 기여를 참고 계산합니다. 도루 실패와 수비 이닝을 알면 따로 입력할 수 있습니다.
- **직접 수정·CSV:** 18개 보정값과 각 출처를 확인·수정하고 원자료·가정·결과를 함께 내보냅니다. 이전 시즌 CSV 형식은 유지했습니다.

## 추정치의 범위

수비는 실측하지 못해 **평균 수비(0)**로 가정합니다. 미확보 고의사구·도루 실패는 리그 비율, 수비 이닝은 경기 수×9를 가정합니다. 실제 입력으로 수정할 수 있으며 화면과 CSV에 이 구분을 표시했습니다. 주루는 wSB만이며 진루 전체를 측정한 BsR가 아닙니다. 공식 fWAR/bWAR, 투수 WAR, 게임 리그 전체를 실측한 WAR라고 표시하지 않습니다.

## 유지한 기능과 보류한 연구

이전 공개판의 F6/F7/F8·속도·대상 범위·전술·난입·교체·훈련·세이브 편집 및 기본 설정을 변경하지 않았습니다. CT와 내장 기능 팩도 그대로입니다. 새 계산기는 게임·세이브에 쓰지 않습니다.

추가 CPU 수비 판단, 페넌트 선택 선수의 개인 다이제스트, 재시작 뒤 훈련 이월 파일 불러오기는 새 연구분으로서 이번 패키지에는 넣지 않았습니다. 기존 수비 설정·스타 다이제스트·연결 중 성장 이월은 유지합니다. 주루 애니메이션, 실시간 궤도 색·크기, 4축 레벨 편집은 완성 기능으로 안내하지 않습니다.

사용 위치와 계산 가정은 [전체 설명서 95~96장](https://github.com/PrimeTimerer/ProspiStudio/blob/main/USER_GUIDE_0_7_224.ko.md)을 참고하세요. 기존 LAB의 실제 경기 확인이 필요한 부분도 설명서에 구분했습니다.
