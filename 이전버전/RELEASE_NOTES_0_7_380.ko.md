## 바뀐 것 (0.7.379~0.7.380)

- **사용자 타석 자동 감지 (0.7.379, GitHub #10·#6)**: 빅리그식 타격(클래식)을 켜면 페넌트 팀 플레이에서 CPU 타자들이 스윙을 하지 않던 문제를 고쳤습니다. 내가 조작하는 투수를 찾지 못하면(예: 적용 대상이 ‘직접 조작 선수만’일 때) 그 타석을 내 타석으로 보고 클래식 조준·연습 스윙·체크·스윙 판정을 CPU 타석에 걸었고, 내가 던지는 공에도 클래식 조준이 걸려 CPU 타자의 스윙 위치가 바뀌었습니다. 이제 게임의 경기 단계(내 팀이나 내 선수가 수비·주루 중, 전술 경기)를 읽어 내 타석이 아니면 타격 기능을 걸지 않습니다. 단계를 모를 때는 예전처럼 동작합니다. 빅리그식 투구만 켠 경우에는 CPU 타자가 정상적으로 스윙하는 것을 실제 경기에서 확인했습니다.
- **CPU 투구 스트라이크/볼 비율: 스타플레이어 타자 (0.7.379, GitHub #9)**: 스타플레이어에서 타자로 직접 플레이할 때 모든 공이 ‘그대로 둠 · 그 밖’으로만 세어지고 비율이 적용되지 않던 문제를 고쳤습니다. 이제 상대 CPU 투수가 내 선수에게 던지는 공에 적용됩니다. 자동으로 치는 팀 동료 타석과 내 팀이 수비할 때는 그대로입니다. 페넌트는 예전과 같습니다.
- **스피리츠 단축키를 빅리그식 타격 위에 (0.7.380)**: 빅리그식 타격(클래식)을 켜면 F3 베스트 히팅, F9 상황별 평타·강진 타구 매트릭스(F7 공격 묶음 포함), Num 4~6 타구 궤적이 효과가 없던 문제를 고쳤습니다. 빅리그식 타격이 타구를 마지막에 다시 써서 그 기능들이 덮였습니다. 이제 켜 두면 빅리그식 스윙에도 그 효과가 얹힙니다. F3은 공 쪽으로 맞혀 정타가 나게 하고(타이밍은 그대로 판정), F9는 그 LAB의 표대로 평타·강진 타구를 정하며, Num 4~6은 맨 마지막에 속도·각도를 정합니다. 좌우 방향은 빅리그식 그대로이고, 스윙 기록에 무엇이 적용됐는지 나옵니다. F6(수비 묶음)·Num 1~3(구속)·Num 7~9(무게)는 투구 기능이라 이번 변경과 관계없습니다.
- **뜬공이 뚝 떨어지던 문제 (0.7.380)**: 빅리그식 타격이 타구의 속도·각도를 바꿀 때 게임의 회전을 그대로 두어, 땅볼을 뜬공으로 바꾼 타구가 톱스핀으로 뚝 떨어지거나 팝플라이처럼 보였습니다. 이제 바뀐 발사각 쪽으로 회전 방향을 맞춥니다(위로 뜨면 백스핀, 아래로는 톱스핀). 회전 크기는 그대로이고, 방향이 바뀐 스윙은 기록에 ‘회전’으로 나옵니다.
- **미터 투구가 중간에 풀리던 문제 (0.7.380)**: 빅리그식 투구에서 가끔 미터가 나오지 않고 스피리츠 기본 투구로 던져지던 문제를 고쳤습니다. 게임 창이 맨 앞에 있지 않을 때(예: Studio 창을 눌러 둔 상태) 누른 패드 버튼은 미터 시작으로 쓰지 않았는데, 게임은 그 버튼을 받아 던졌습니다. 이제 그 버튼으로도 미터가 시작되고, Studio 창이 앞에 있어도 게임 화면 위에 미터가 보입니다(다른 프로그램 위에는 여전히 보이지 않음). 투구 동작 감지가 잠깐 늦은 경우에도 직전에 누른 투구 버튼으로 미터를 시작합니다. 그래도 미터 없이 던져진 공은 투구 기록에 그 이유가 남습니다. 미터 투구는 직접 끌 때까지 켜진 채로 유지됩니다.

예전과 달라지는 점(0.7.378 대비): 빅리그식 타격(클래식)은 게임이 내 타석이 아니라고 알려 주는 동안(내 팀 수비·주루, 전술 경기) 작동하지 않습니다(단계를 모를 때는 예전처럼). CPU 투구 스트라이크/볼 비율 LAB(기본 꺼짐)은 스타플레이어 타자 직접 플레이에서도 적용됩니다. 빅리그식 타격을 켠 채 F3·F9(F7 묶음 포함)·Num 4~6을 켜 두면 그 효과가 빅리그식 스윙에도 얹힙니다(예전에는 효과 없음). 빅리그식 타구의 회전은 발사각 쪽으로 맞춰집니다. 빅리그식 투구의 미터는 게임 창이 맨 앞이 아닐 때 누른 패드 버튼으로도 시작하고, Studio 창이 맨 앞일 때도 게임 위에 보입니다. 나머지는 0.7.378과 같습니다.

## 아직 확인 중인 것

- 페넌트 팀 플레이에서 빅리그식 타격(클래식)을 켠 채 CPU 타석의 스윙(적용 대상 ‘직접 조작 선수만’ 포함)
- 스타플레이어 타자로 CPU 투구 스트라이크/볼 비율 LAB의 집계(존 안으로 뽑힘·안으로 옮김)
- 빅리그식 타격(클래식)을 켠 채 F3·F7·F9의 정타와 Num 4~6의 타구 궤적, 뜬공의 비행
- 미터 투구: 긴 경기에서도 미터가 풀리지 않는지(풀리면 투구 기록의 이유)
- 자동 업데이트: 0.7.378에서 이번 버전으로의 실제 업데이트
