## 바뀐 것 (0.7.389)

- **다음 투구 준비를 새 투구로 잘못 세던 문제 수정 (0.7.389, 빅리그식 타격 클래식)**: 빅리그식 타격(클래식)에서 체크 스윙을 한 뒤 장면이 바로 넘어가지 않던 문제를 마저 고쳤습니다. 투구가 끝나고 약 1초 뒤 게임이 다음 공을 미리 계산하는데, Studio가 이것을 새 투구로 잘못 보고 넘기기 버튼을 체크 스윙으로 바꿨습니다. 공이 손을 떠나기 전에 한 체크 스윙도 이제 다음 투구 전까지 넘기기가 됩니다.

예전과 달라지는 점(0.7.388 대비): 조작 규칙은 같고, 다음 투구 준비를 새 투구로 잘못 세던 문제만 고쳤습니다.

## 아직 확인 중인 것

- 빅리그식 타격(클래식): 체크 스윙이나 그냥 보낸 공 뒤에 여러 번 눌러도 장면이 넘어가고 체크 동작이 다시 나오지 않는지
- 자동 업데이트: 0.7.388에서 이번 버전으로의 실제 업데이트
