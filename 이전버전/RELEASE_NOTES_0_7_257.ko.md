## 바뀐 것

- **게임 설정 잠금 풀기: 모든 오프라인 모드** (0.7.257): 고시엔에서만 되던 잠금 풀기와 카메라 9가지가 이제 오프라인 모드 전부(엑시비전·대전, 페넌트, 스타플레이어, 고시엔, 그랑프리, WBC 2026, 연습, 라이브 시나리오, 홈런 더비, 튜토리얼)에서 됩니다. 게임이 지금 돌리는 모드의 이름으로 모드를 구별하고, 온라인 대전·온라인 메뉴와 이름을 모르는 모드(스피리츠 등)는 그대로 잠가 둡니다. 온라인을 하고 나온 직후 메인 메뉴에서 연 설정 화면도 온라인으로 봅니다. 카드에 지금 모드와 풀림·잠금 유지가 나옵니다.
- **게임 설정 잠금 풀기** (0.7.256, LAB, 기본 꺼짐): 게임 ‘유저 설정’ 화면에서 모드 때문에 회색으로 잠긴 항목(예: 고시엔의 CPU 난이도 전부, 타격 시스템, 콘택트·투구 어시스트, 스트라이크 존, 투구 예측점·폼, 주자·수비 조작, 선수명·특수 능력·타자 능력 표시)을 바꿀 수 있게 합니다. 켠 뒤 게임에서 설정 화면을 다시 열면 적용됩니다. 끄면 원래대로 잠깁니다. 저장된 설정이나 게임 파일은 건드리지 않습니다.
- **투구·타격 카메라 9가지** (0.7.256): 같은 LAB이 켜져 있으면 ‘투구 화면’과 ‘타격 화면’에서 모드에 따라 5가지나 4가지로 줄어 있던 카메라를 9가지 모두 고를 수 있습니다.

예전과 달라지는 점: 새 LAB ‘게임 설정 잠금 풀기’(기본 꺼짐)뿐입니다. 켜지 않으면 게임 설정 화면은 예전과 같습니다. 켜면 오프라인 모드의 회색 항목과 줄어 있던 카메라 목록이 풀리고, 온라인은 그대로입니다.

## 아직 확인 중인 것

- 고시엔 외 오프라인 모드(페넌트·스타·엑시비전 등)에서 회색 항목이 풀리는지, 카드에 지금 모드가 ‘풀림’으로 나오는지
- 바꾼 CPU 난이도·어시스트·카메라가 경기에 실제로 들어가는지
