## 바뀐 것 (0.7.362~0.7.367)

- **스피리츠식 투구 + 제구 랜덤 (0.7.367, 기본 꺼짐)**: 빅리그식 조작 시스템 › 투구 탭에서 맨 위 빅리그식 투구 스위치를 켜고 ‘미터 투구’는 끈 채 이 옵션을 켜면, 스피리츠의 2번 누르기 투구를 그대로 쓰고 미터는 나오지 않습니다. 공은 게임의 타이밍 판정에 따라 빗나갑니다. 저스트는 조준한 곳으로 가고, 약간 이름·약간 늦음은 조금, 늦음·아주 이름·아주 늦음은 크게(이르면 높게, 늦으면 낮게) 빗나갑니다. 빗나가는 크기는 제구 랜덤과 같은 계산이라 제구가 좋을수록 작고, 같은 탭의 구종 제구 반영·컨디션 반영·포수 리드 반영·완벽일 때 설정도 함께 적용됩니다.
- **투수 타석 대타 → 등판 예약 (0.7.367)**: 난입·교체 요청 (선수 조작)의 예약 종류에 ‘투수 타석 대타 → 등판’이 생겼습니다. 시작 이닝을 고르고 ‘매 경기 반복’을 켜 두면 그 이닝 이후 투수 타석에 대타로 들어간 뒤 다음 수비 때 투수로 올라갑니다(홀드·세이브 기록용). 지명타자가 있는 경기는 투수가 타석에 서지 않으므로 건너뜁니다.
- **지금 상대 투수 강판 (0.7.367)**: 공통 경기기능의 CPU 선발 강판 LAB 카드에 ‘지금 상대 투수 강판’ 버튼이 생겼습니다. LAB을 켜지 않아도 누르는 순간 마운드에 있는 상대 투수(선발·구원 모두, 몇 회든)의 경기 체력을 0으로 만들어, 게임 감독이 다음 판단(다음 타자 전) 때 교체합니다. 남은 투수가 없으면 계속 던질 수 있습니다.
- **확정 홈런 모션 번호 (0.7.367)**: DIRECT 선수 편집과 세이브 편집의 타격폼 칸에 ‘확정 홈런 모션 번호’가 생겼습니다. 홈런 직후 배트를 던지는 동작 같은 확정 홈런 모션은 타격폼과 따로 선수에게 붙어 있어서, 다른 선수의 타격폼만 가져오면 그 동작은 따라오지 않았습니다. 선수 데이터(현역·OB·WBC)에서 원하는 선수의 번호를 보고 같은 번호를 넣으세요(0은 자동, 1~84 중 53 제외).
- **자동 양투 → 글러브도 같이 (0.7.367, 동작 변경)**: 자동 양투를 켜면 ‘글러브 손 따라가기’도 함께 켜져, 던지는 손이 바뀔 때 글러브가 반대 손으로 옮겨집니다(예전에는 따로 켜야 했음). DIRECT에서 양투로 표시한 선수도 처음 손이 바뀔 때 함께 켜지고, 글러브를 따로 끄면 그대로 꺼져 있습니다.
- **포수 리드 반영 (0.7.366, 기본 꺼짐)**: 빅리그식 투구에서 수비 포수의 포수 리드 등급이 미터 판정 폭(G 0.8배 … S 1.2배)과 제구 랜덤의 빗나감(G 1.25배 … S 0.8배)에 반영됩니다. 포수를 모르면 둘 다 1배이고, 상태 줄에 ‘포수 리드 B’처럼 나옵니다.
- **스피리츠 투구 원 숨기기 (0.7.366, 기본 꺼짐)**: 미터 투구로 내가 던질 때 릴리스 약 0.6초 전에 나오는 스피리츠의 타이밍 원을 숨깁니다. 조준 커서와 판정은 그대로입니다.
- **유니폼 선수별 지정 수정 (0.7.366)**: 목록에 넣은 에디트 팀 선수가 팀 에디트의 선수 화면과 대전 경기에서 여전히 에디트 팀 디자인으로 보이던 문제를 고쳤습니다. 목록에 없는 선수, 에디트 팀 디자인을 고른 선수, 빈 목록과 끌 때의 복원은 그대로입니다.
- **세이브 편집 선수 삭제 (0.7.362)**: 페넌트 CPU 구단의 선수를 게임의 선수 빼기와 같이 명단과 구단 기록 표에서 지웁니다. 내 구단 선수는 지울 수 없고, 다른 변경 없이 혼자 저장합니다.
- **능력 최저로 · 은퇴 유도 (0.7.362, 세이브 편집)**: ‘능력 최저로’는 능력치·구종·특능을 최저로 하고 오리지널 구종을 해제합니다. ‘은퇴 유도’는 여기에 나이 40세를 더해 다음 오프시즌에 게임이 은퇴·방출로 정리하게 합니다(확실하지는 않음). 스타 선수는 안 됩니다.
- **해설 음성 고르기 (0.7.362)**: 오리지널 구종 카드에서 게임 오리지널 구종이 쓰는 읽기 14가지 중 하나를 고르면 읽기 칸에 들어갑니다. 세이브 편집에도 ‘읽기만 바꾸기’가 생겼습니다.
- **슬로 모션 수정 (0.7.362)**: 게임이 고정 프레임레이트(60)로 돌아 슬로 모션 (도루·견제) LAB이 걸리지 않던 문제를 고쳤습니다. 이제 슬로 중에는 게임 엔진의 프레임 대기를 늘리고 한 프레임의 시간은 그대로 두어, 공·선수·화면이 고르게 느려집니다. LAB을 끄면 원래대로 돌아갑니다.
- **실패 기록 문구 (0.7.362)**: 호환성 줄이 ‘이 실행 파일의 실패 기록 n건(기능 m개, 예전 기록 포함) · 전체 기록 n/32’로 바뀌었습니다. 숫자와 기록은 그대로입니다.
- **키보드·마우스로도 타격 (0.7.362, 기본 꺼짐)**: 빅리그식 타격에서 스윙 키(기본 마우스 왼쪽)를 패드 버튼처럼 씁니다. Q·E는 컨택·파워, WASD나 방향키는 패드 스틱이 중립일 때 스틱으로 씁니다. 게임 창이 맨 앞일 때만 읽고, 키와 클릭은 게임에도 그대로 갑니다.
- **빅리그식 스윙 손맛 (0.7.363, 기본 꺼짐)**: 타격 탭의 새 카드입니다. 스윙이 시작될 때부터 컨택까지 몸통이 먼저 돌고(머리는 공을 본 채), 배트는 뒤로 더 젖혀졌다가 컨택 직전에 한꺼번에 풀려 나갑니다. ‘배트 젖힘’(기본 30°, 0~45°)과 ‘몸통 먼저’(기본 10°, 0~25°)로 정하고, 컨택 순간 자세와 판정은 게임 그대로입니다.
- **스윙 손맛 기록 · 타격 다이나미즘 단위 (0.7.364)**: 스윙 손맛을 켜면 타격 기록에 스윙마다 자세 프레임과 배트·몸통 각도가 붙습니다. 타격 다이나미즘은 게임 프레임 단위가 됐습니다(0.7.367부터 클래식은 원래 계산을 쓰므로 이 설정을 숨김).
- **존 위치 자동 (0.7.365, 기본 켜짐)**: 빅리그식 타격(클래식)에서 게임 카메라로 존이 화면 어디에 그려지는지 계산해 화살표·스윙 종류 표시·카메라 기울기 중심을 존에 맞춥니다(좌우 타자·검은 띠 포함). 끄면 예전처럼 ‘존 가운데 위치’와 ‘존 크기’를 씁니다. 경기가 바뀐 뒤에도 타자를 다시 찾습니다.
- **빅리그식 타격(클래식) 계산 정리 (0.7.365~0.7.367)**: 클래식은 항상 빅리그식 원래 계산으로 칩니다. 정타는 팝플라이가 되지 않고 뜬공·라인드라이브·강한 땅볼이 되며, 직구 계열은 자동 PCI가 공 쪽으로 15% 당겨져 정타가 조금 더 나옵니다. 효과가 없어진 ‘타격 다이나미즘’ 설정은 클래식에서 숨겨집니다.
- **체크 스윙 (0.7.362~0.7.367)**: 빅리그식 타격(클래식)에서 버튼을 빨리 떼면 원래 정지 시각에 타자 자세가 멈추고(약 1초) 준비 자세로 돌아옵니다. 스피리츠 모션이 풀스윙을 이어 그리지 못하게 자세를 직접 그리고, 볼카운트도 스윙 아님으로 처리합니다.
- **타석 시작부터 카메라·화살표 · 휘는 타구 라인 (0.7.362)**: 스틱 카메라·화살표·스윙 종류 표시가 타격 커서가 뜰 때(와인드업 전)부터 나옵니다. 늦은 컨택 스윙에 휘어 나가는 타구는 파울 라인 쪽으로 최대 12°까지 휘되 페어 안에 머뭅니다.

예전과 달라지는 점(0.7.361 대비): 새 기능은 기본 꺼짐이거나 고를 때만 작동합니다. 바뀌는 동작은 다음과 같습니다. 자동 양투를 켜면 글러브 손 따라가기도 함께 켜집니다(예전에는 따로 켜야 했음). 슬로 모션 (도루·견제) LAB은 고정 프레임레이트 게임에서도 걸리고, 유니폼 선수별 지정은 목록의 선수에게 제대로 적용되며, 호환성 줄의 실패 기록 문구가 바뀌었습니다(숫자는 같음). 빅리그식 타격(기본 꺼짐)을 켜지 않았다면 타격 동작은 같습니다. 빅리그식 타격(클래식)을 켜 두었다면 항상 원래 계산으로 치고(정타는 팝플라이가 되지 않고 직구 정타 보정 15%), 존 위치 자동이 기본으로 켜지며(끄면 예전 수동 위치), 체크 스윙은 자세가 멈췄다 돌아오고, 카메라·화살표는 타격 커서가 뜰 때부터 나오며, 효과가 없어진 타격 다이나미즘 설정은 숨겨집니다.

## 아직 확인 중인 것

- 스피리츠식 투구 + 제구 랜덤의 빗나감(이름·저스트·늦음), 포수 리드 반영, 스피리츠 투구 원 숨기기
