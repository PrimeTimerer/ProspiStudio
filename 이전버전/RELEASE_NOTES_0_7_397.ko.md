## 바뀐 것 (0.7.397)

- **체크 스윙 멈춤 수정 (0.7.397, 클래식)**: 빅리그식 타격(클래식)에서 공이 이미 배트에 맞은 뒤에 버튼을 떼면 체크 스윙으로 처리되어, 타구는 날아가는데 타자가 뛰지 않고 경기가 멈추던 문제를 고쳤습니다. 이제 공이 맞은 뒤에 뗀 버튼은 스윙 그대로 둡니다(GitHub 이슈 #12).
- **체크 스윙 판정 수정 (0.7.397, 클래식)**: 빅리그식 타격(클래식)에서 체크·하프 스윙을 해도 게임 판정에는 스윙으로 남아, 존 밖 공도 스트라이크가 되던 문제를 고쳤습니다. 이제 체크·하프 스윙은 존 밖이면 볼, 존 안이면 스트라이크가 됩니다(GitHub 이슈 #12).

예전과 달라지는 점(0.7.396 대비): 공이 배트에 맞은 뒤에 뗀 버튼은 체크 스윙이 되지 않고 스윙 그대로 남습니다. 체크·하프 스윙한 공은 이전에는 존 밖이어도 스트라이크였지만 이제 볼이 됩니다.

## 아직 확인 중인 것

- 빅리그식 타격(클래식) 체크 스윙: 공이 맞은 뒤 버튼을 떼도 타자가 뛰고 경기가 이어지는지, 존 밖 공에 체크하면 볼이 되는지
- 자동 업데이트: 0.7.396에서 이번 버전으로의 실제 업데이트
