## 새로 추가된 기능

- **관전 모드 (LAB):** 선수 플레이에서 내 선수가 관여하지 않아 게임이 뒤에서 결과만 계산하던 투구를 실제 경기 장면으로 보여 줍니다(공격·수비 관전, 스타·페넌트·고시엔·엑시비전 등). 관전 배속은 빠른 진행으로 정합니다.
- **다음 내 차례까지 건너뛰기 (LAB):** 경기 중 한 번 누르면 내 타석(설정에 따라 내 투구)까지 다른 플레이를 게임의 다이제스트로 건너뜁니다. 단축키는 고를 때만 생깁니다.
- **빠른 진행:** 게임 자동 진행(다이제스트)·고속경기 때만 쓰는 배속(원래대로, 1배속, 2~10배; 기본 원래대로).
- **전술 경기:** 고시엔 전술 경기 LAB 옵션 스타 전술 경기 안정 모드·고유 카드(능력 기준 자동, DIRECT에서 선수별 지정)·전령(주장 지정), 새 LAB 전술 경기 횟수 무제한과 내 선수만 전술 카드(반대 방향 포함).
- **통합 상황실:** ② 자동 유지(페넌트 9종·스타 7종), ③ 직접 효과 241종, ④ 연봉·계약·FA·구단 자금, 외부 설정(.p26profile) 저장·불러오기, 고시엔·엑시비전 보기와 스피리츠 안내.
- **고시엔 상대 학교:** 경기 중 상대 능력 N%, 상대 학교 성장 N%, 영구 조정(되돌리기 가능). 내 학교는 바꾸지 않습니다.
- **센트럴 리그 DH 제도 (LAB):** 페넌트·스타에서 센트럴 구장 홈경기도 퍼시픽 방식 DH(정규 시즌·클라이맥스·일본시리즈·교류전 선택). 이도류 옵션 3종(LAB).
- **오타니 쇼헤이의 스위퍼:** 게임 원본 기록을 특능·오리변 가져오기와 오리지널 라이브러리에서 씁니다.
- **세이브 편집:** 스타 본인 선수 가져오기(세 사본, 성장 경험치 맞춤).
- **자유행동일:** 하루 1번(휴일에 개인 생활 1번)과 휴일 아이템(옵션).

## 옵션을 고르지 않아도 달라지는 점

- **스타 전술 경기:** 출전일 판정을 게임의 오늘 역할 검사로 바로잡았습니다(지난 준비 값 때문에 엉뚱한 날이 통과되거나 막힐 수 있었음). 거부된 요청은 지웁니다(예전에는 남아서 다음 페넌트 감독 플레이가 전술 경기로 바뀔 수 있었음). 카드에 최근 단계가 보이고 날짜별 로그가 남습니다.
- **DIRECT 특수 능력 90:** 표본에 없는 조합을 첫 항목(D/없음) 대신 '현재값'으로 보여 줍니다. 능력 카드의 이름·색·탭은 게임 표시 규칙을, 특능·오리변 가져오기 목록의 이름은 게임 이름을 따릅니다. 쓰는 값은 그대로입니다.
- **등급형 안전 MAX와 청특 지우기(DIRECT·세이브 편집):** 안전 MAX는 지금 등급을 낮추지 않고, 청특 지우기는 바꾸는 칸만 검사합니다(예전에는 다른 칸의 표본 밖 조합 때문에 전체를 거부).
- **원래 통합 패널:** 페넌트·스타 선수·구단 편집 탭에서 LAB → 옮긴 원본으로 옮겼습니다(그대로 작동). 한눈에 보기 카드와 페넌트 자동 유지 안내는 통합 상황실을 열고, 즐겨찾기 창에서는 '다른 모드·전체 기능'에 있습니다.
- **모드별 기능 OFF:** 통합 상황실 자동 유지, 고시엔 상대 학교의 두 기능, 센트럴 리그 DH·이도류 LAB도 그 모드의 OFF로 꺼집니다.
- **일정 탭과 난입·교체 캘린더:** 게임의 DH 설정을 바꾼 시즌에도 경기 날짜를 표시합니다(기본 설정에서는 예전과 같음).
- **화면 오류:** 검은 빈 창 대신 그 화면 안의 오류 상자(다시 그리기) 또는 화면 다시 불러오기 페이지가 나오고, 오류와 드래프트 읽기·실패한 명령이 진단 로그에 남습니다.
- **연봉 최대값:** DIRECT 페넌트 명단과 페넌트 자동 유지가 연봉 원값 2,000,000,000인 선수도 포함합니다.
- **오타니 쇼헤이의 스위퍼:** 게임 원본과 똑같은 기록은 확인된 구종으로 봅니다(그 선수도 '확인 안 된 구종'으로 표시되지 않음).
- **관대 호환 모드(검토되지 않은 실행 파일에서만):** 선택 부분만 다른 LAB을 호환성 화면에서 잠김으로 표시하지 않습니다(설치는 원래 막지 않았음). 자동 경기로 끝까지는 메뉴 행 표시 보정을 확인하지 못하면 거부하는 대신 0.7.214 방식(행은 보이지 않지만 선택 가능, 일반 모드만)으로 켭니다.

## 설치와 확인 범위

게임 세이브를 따로 백업하고 Studio를 메뉴에서 정상 종료한 뒤 새 EXE를 사용하세요. 설정 폴더나 게임 파일을 지울 필요는 없습니다. Windows x64의 .NET 6 Desktop Runtime x64와 WebView2 Runtime이 필요합니다.

코드·UI·배포 패키지·롤백·단일 EXE 검사와 기존 기능의 회귀 검사를 통과했습니다. 새 기능의 실제 경기 확인과 게임이 편집된 세이브를 불러오는 확인은 아직이며, 스타 전술 경기 클릭 튕김의 정확한 원인은 크래시 덤프 확인 전입니다. 새 기능은 별도 세이브에서 먼저 확인하세요.
