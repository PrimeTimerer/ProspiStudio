## 바뀐 것 (0.7.421)

- **빅리그식: 게임이 받은 입력 (GitHub #25)**: 빅리그식 조작 시스템의 ‘패드’ 선택에 ‘게임이 받은 입력 (Steam 입력 패드 등)’이 생겼습니다. Studio가 패드를 직접 찾지 못할 때(Steam 입력으로 쓰는 스위치 프로·8BitDo 같은 패드 등) 게임이 받은 패드 입력을 읽어 빅리그식 투구·타격에 씁니다. 기본 선택(처음 연결된 패드)과 다른 선택은 그대로입니다.
- **같은 구종 연속 보정 끄기 (GitHub #27)**: 게임은 같은 타석에서 앞 공과 같은 구종(또는 같은 계열)을 던지면 CPU 타자의 조준을 더 정확하게 하고 스윙 확률을 5%p 올립니다. 공통 기능의 ‘같은 구종 연속 보정 끄기’(기본 꺼짐)를 켜면 이 보정이 없어져, 결과가 체력·투구 정확도·능력으로 정해집니다. ‘구속 차이까지’를 고르면 앞 공과의 구속 차이 보정(구속이 비슷하면 CPU가 더 잘 맞히고, 크게 바꾸면 덜 맞히는 것)도 끕니다. 타석 첫 공과 능력·볼카운트 보정은 그대로이고, 모든 모드의 CPU 타자에게 적용됩니다.
- **불펜·마무리 투타겸업 (LAB, GitHub #28)**: 게임은 선발 유형 스타에게만 투타겸업 야수 출장일을 줍니다. 스타플레이어 › 성장·생활·아이템의 ‘불펜·마무리 투타겸업 (LAB)’(기본 꺼짐)을 켜고 간격(매 경기일~7일마다)을 고른 뒤, 내 선수 생활 › 팀내 위상에서 투타겸업을 켜면 계투 유형 스타도 그 간격마다 게임의 투타겸업 야수 출장일로 나오고 다른 날은 불펜입니다. 실제 경기에서의 오더·기용은 확인 중인 실험 기능입니다.

예전과 달라지는 점(0.7.420 대비): 세 기능 모두 새로 생긴 선택이라 고르거나 켜기 전에는 아무것도 바뀌지 않습니다. 팀내 위상의 ‘투타겸업 켜기’는 불펜·마무리 투타겸업 LAB이 켜져 있을 때만 계투 유형에도 됩니다(꺼져 있으면 예전처럼 선발 유형만).

## 문제 제보 방식 (0.7.405부터)

- Studio와 CT 둘 다 수만 줄 규모의 큰 프로그램이 되어, 실제 로그와 화면 캡처 없이 설명만으로는 문제를 찾아 고치기가 거의 불가능합니다.
- 그래서 갤러리 댓글로 주신 제보·요청에는 대응하지 않습니다. 문제는 [GitHub 이슈](https://github.com/PrimeTimerer/ProspiStudio/issues)에 올려 주세요. 갤러리라면 최소한 따로 글을 쓰고 아래 자료를 모두 붙여 주셔야 확인할 수 있습니다.
- 함께 올릴 것: Studio 버전, 게임 모드와 상황(경기 중인지 메뉴인지 등), 켠 기능(카드·LAB 이름과 설정), 문제가 생기기까지의 순서, 화면 캡처(Studio 화면과 게임 화면), 로그 파일, 게임이 튕겼다면 크래시 파일
- 로그: `%LOCALAPPDATA%\Prospi26Studio\logs` 폴더의 최근 파일(빅리그식 조작 시스템의 ‘로그 폴더’ 버튼으로도 열립니다)
- 크래시 파일: `%LOCALAPPDATA%\prospi\Saved\Crashes`에서 가장 최근 폴더를 통째로 압축(UE4Minidump.dmp 포함)
- 0.7.406~0.7.417도 화면 캡처, Studio 버전, 재현 순서가 정확히 적힌 GitHub 이슈(#15, #16, #18, #19, #20, #21, #25)와 캡처를 붙인 갤러리 글 덕분에 바로 원인을 찾아 고쳤고(0.7.414는 제보와 함께 올려 주신 세이브, 0.7.416은 오류 창 캡처로 확인), 0.7.410·0.7.412·0.7.415·0.7.417의 새 기능도 GitHub 이슈(#17, #19, #21, #24) 건의로 만들었습니다.

## 아직 확인 중인 것

- 게임이 받은 입력(#25): Steam 입력으로 쓰는 패드에서 빅리그식 투구·타격이 되는지(제보해 주신 분의 확인 대기)
- 같은 구종 연속 보정 끄기(#27): 같은 구종을 이어 던질 때 맞는 비율이 줄고, 결과가 투구 정확도·체력을 따르는지(건의해 주신 분의 확인 대기)
- 불펜·마무리 투타겸업(#28): 계투 유형 스타가 정한 간격마다 야수로 오더에 들어가고 다른 날은 불펜으로 나오는지(건의해 주신 분의 확인 대기)
- 후보 이름 목록에도 전체 이름: 켠 뒤 게임의 후보 목록에 ‘김민준’처럼 전체 이름이 나오는지, 상세 화면·드래프트 회의·지명된 신인의 이름(건의해 주신 분의 확인 대기)
- 스타 부상 실험: 부상을 넣은 선수가 오더에서 빠지는지, 남은 일수가 날마다 줄어드는지, 큰 부상이 2군으로 가는지(써 보신 분의 결과 대기)
- 빅리그식 타격 LB 컨택 · RB 파워: 좌타·우타·스위치 타자 모두 LB와 함께 컨택, RB와 함께 파워 스윙이 나가는지
- 빅리그식 진단 로그(#25): 빅리그식이 작동하지 않는 PC의 show-system 로그로 원인이 보이는지(제보해 주신 분의 확인 대기)
- 패치 게임(#25): 한글패치·KBO 패치 게임에서 빅리그식 투구·타격이 다시 작동하는지, Studio 위쪽 안내의 꺼 둔 기능 수(제보해 주신 분의 확인 대기)
- 투타겸업 켜기·끄기: 다음 날 시작부터 투수 출전일만(끄기) 또는 야수 출전일도(켜기) 나오는지
- 에셋 스튜디오 GPU 미리보기: 투구폼 애니메이션 편집의 ‘GPU 3D 기본 Body 메시’ 탭에 오류 창 없이 3D 몸체가 나오는지, GPU 재질 미리보기와 원본 3D 유니폼 창(제보해 주신 분의 확인 대기)
- 선발일 중계(#21): 계획한 선발일에 다음 투수가 선발로 나오고 스타가 불펜에서 기다리다 정한 이닝에 들어가는지, 다음 경기 스타 선발(건의해 주신 분의 확인 대기)
- 선수 가져오기 대상(#20 추가 보고): 팀 공유로 받은 팀의 선수에게 외모·투타 폼이 들어가는지, 저장 뒤 게임에서 불러오기(제보해 주신 분의 확인 대기)
- PCI 타격 스윙 타이밍 표시: 경기에서 PCI 스윙 뒤 게임 화면 위쪽에 타이밍이 뜨는지
- 무조건 파울을 일반 타격에도: 빅리그식 타격을 끈 경기에서 고른 범위의 맞힌 공이 파울로 돌아가 타석이 이어지고, 헛스윙은 그대로인지(건의해 주신 분의 확인 대기)
- 코드 패치 전 스레드 오류(#18): 제보해 주신 PC에서 기능이 켜지고 꺼지는지(제보해 주신 분의 확인 대기)
- 후보 이름 한국식으로: 게임의 드래프트 후보 목록(다시 연 뒤), 지명된 신인의 선수단 이름, 저장 뒤 다시 불러오기(건의해 주신 분의 확인 대기)
- 선발 등판일에 멈추기: 고른 투수의 선발일 아침에 스킵 종료 확인 창이 뜨고 끝내기를 고르면 그날 메뉴에서 멈추는지, 다른 투수의 선발일에는 그대로 넘어가는지, 포스트시즌(클라이맥스 시리즈·일본시리즈)
- 연봉 상한 바꾸기(0.7.408): 상한을 올린 스타의 연봉 협상에서 1차 미팅 보류 뒤 2차 미팅이 꺼지지 않고 진행되는지(제보해 주신 분의 확인 대기)
- 스타 트레이드: 신청한 선수가 다음 날 시작 때 우리 구단으로 옮겨지는지, 게임 트레이드 소식과 그날 오더, 저장 뒤 다시 불러오기, 게임 규칙에 걸린 신청의 안내
- 자동 업데이트: 0.7.420에서 이번 버전으로의 실제 업데이트
