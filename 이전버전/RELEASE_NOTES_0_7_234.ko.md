# PROSPI 26 STUDIO 0.7.234

**게임 2.3.0용 버전입니다.** 2026년 10월 8일 Steam 업데이트로 게임이 2.3.0이 됐습니다. 0.7.233 이하 Studio(공개판 0.7.224 이하)는 2.2.0 기준이라 2.3.0에서는 쓸 수 없고, 0.7.234는 2.2.0 게임을 지원하지 않습니다. 직전 공개판 0.7.224 이후의 로컬 배포분(0.7.225~0.7.233)과 2.3.0 대응을 모두 포함합니다. 로컬·오프라인 싱글플레이 전용입니다.

## 게임 2.3.0 지원

- 모든 DIRECT 기능(경기 조작·LAB·드래프트 등 73개)을 2.3.0 실행 파일에서 위치와 원래 바이트를 다시 확인해 옮겼습니다. 이 버전에서 꺼진 기능은 없습니다. 내장 기능 팩도 업데이트로 위치가 바뀐 값만 2.3.0에 맞췄습니다.
- 2.3.0이 CPU 지명 처리를 새로 만들어 드래프트 네 옵션(지명 보호, 중복 지명 · 내 구단 당첨, 스타 드래프트 지명 순서·다른 구단 보호, 우리 구단 당첨)을 다시 만들었습니다. 후보 번호는 1~409,999까지 받습니다.
- 2.3.0이 저장한 세이브를 세이브 편집에서 열고 편집하며, 리그 훈련 이월 장부도 2.3.0 세이브에 연결합니다. 영어 이름표·내장 명단·고시엔 이름 목록·모션 폼 목록을 2.3.0 기준으로 읽습니다.
- 2.2.0 실행 파일과 2.2.0용 한국어 패치 V1.4는 확인되지 않은 버전으로 봅니다. 2.3.0용 한글패치는 아직 확인하지 못했습니다(데이터만 바꾼 실행 파일은 순정 2.3.0 코드와 같은지로 확인).
- 실행 중인 2.3.0 게임에서는 읽기만 해서 게임 위치·모드 데이터 위치·드래프트 후보 번호 등을 확인했습니다. 기능을 켜서 효과를 보고 끄고 저장·재접속하는 실제 게임 확인은 진행 중입니다(설명서 123장).

## 새로 추가된 기능

### 공통

- **옵션 기억** (0.7.234): 각 모드와 공통 기능 화면 위쪽에서 카드 값을 모드별로 기억해 다시 켠 뒤 넣고, 지난번에 켠 기능을 버튼으로 다시 켭니다. 자동 다시 켜기는 기본 꺼짐이고 게임에는 쓰지 않습니다.
- **유저 옵션·카메라 화면** (0.7.232): 공통 기능 › 카메라·옵션에서 58가지 옵션을 고르고 적용·원래대로·설정 파일 저장/불러오기. 원래 패널(#700000)은 LAB › 옮긴 원본.
- **성능 · 게임 랙 관리** (0.7.232): CPU·메모리 읽기·게임 정지 시간을 보여 주고 우선순위 낮추기·화면 갱신 멈추기·간격 ×2/×4 옵션(기본은 예전과 같음).
- **홈런 세리머니·NPB 뉴스 화면** (0.7.234): 공통 패널 맨 위에서 선수 한 명의 세리머니 세 값·자동 랜덤·NPB 뉴스 잠금 우회. 원래 패널(#5920)은 LAB › 옮긴 원본.

### 선수 편집·DIRECT

- **외모·능력 복사** (0.7.231·0.7.232): 스타·페넌트·고시엔 선수 편집 맨 위에서 원본의 외모(얼굴·체격·키·체중)·능력·구종·투타·폼·음성콜·이름·생일·고향을 골라 옮기고, 개수 제한 없는 슬롯에 보관합니다.
- **이름·등번호** (0.7.232): DIRECT와 세이브 편집에서 성·이름·등록명과 등번호를 바꿉니다(같은 구단 중복 번호는 거부).
- **작성 중 선수 · 시작 전과 스타 어필 포인트·자유 선택** (0.7.228~0.7.230): 선수 작성 화면의 선수를 편집하고, 스타 어필의 남은·총 코스트와 116종 어필 순서를 정합니다(기본 OFF).
- **가져오기·시즌 이력** (0.7.231): 스타 본인과 스타 리그 선수에게도 엽니다.

### 기록·세이버 (스타·페넌트·고시엔)

- **기록·세이버 탭** (0.7.225·0.7.226): 원본 세이브로 기록 보관함을 만들고 선택형 자동 수집으로 64개 기록·32개 비율·FIP를 연도·대회·경기별로 봅니다. 떠난 선수 기록 보존, 영어 이름 검색, xlsx·CSV 내보내기·가져오기.

### 페넌트

- **트레이드 무조건 성공** (0.7.234, 기본 OFF): 내 구단 요청에 대한 상대 구단의 판단을 성공으로 바꿉니다. 인원·포수·자금·기간 규칙은 그대로입니다.
- **드래프트** (0.7.232·0.7.234): CPU 지명 보호를 모든 라운드와 다시 불러오기까지 넓히고, 후보 줄에 경력·나이·고향·체격과 내가 바꾼 후보를 표시합니다.
- **다이제스트 3·4번** (0.7.227·0.7.232): 선택 선수 타석만 직접, 포스트시즌은 전 경기 보기.
- **각성 능력 적용·리그 이월 장부** (0.7.227): 고른 구단·선수에게 게임의 실제 각성 사본 적용, 이월분을 게임 재시작 뒤 이어 쓰는 장부 보관·복원.

### 스타플레이어

- **스타 확장 관리 화면** (0.7.234): 인물 우정 변화 배율, 타격 루틴·더그아웃 세리머니(실험값). 원래 패널(#740001)은 LAB › 옮긴 원본에서 그대로 작동.
- **스타 드래프트** (0.7.232): 우리 구단이 고른 후보를 고른 순서대로 지명, 다른 CPU 구단 지명 보호, 우리 구단 당첨.
- **4축 점수 올리기** (0.7.232): 세이브 편집과 실행 중 게임에서 실적·인기·교류·자산 점수를 올립니다. 보상은 게임이 다음 날 직접 처리합니다.
- **수비 장면 '안 함'** (0.7.232, 다이제스트 5번)과 **스타 리그 배율**, 한눈에 보기 카드.

### 고시엔

- **통합 상황실 고시엔** (0.7.232): 내 학교 부원에게 직접 효과 144종, 자동 유지, 학교 자금 1회 적용·유지.

### 세이브 편집

- 2.3.0 세이브, 4축 점수 올리기, 등번호, 스타 리그 선수 가져오기와 외모·능력 복사 슬롯 원본, 선택 구단·선수 각성 능력 적용.

### 스피리츠

- 스피리츠 전용으로 바뀐 기능은 없습니다. 유저 옵션·카메라 화면과 옵션 기억(공통)이 스피리츠 경기와 카드에도 적용됩니다.

### LAB (기본 OFF)

- **레이저 궤적 (실시간)** (0.7.232): 실제 경기 중 투구·타구 뒤의 궤적 선, 구종·타자별 색.
- **인스턴트 구종 칸별 시각 효과** (0.7.233): 구종 칸마다 궤적 선·빛·무지개 꼬리와 로진 연기·구장 폭죽 입자.
- **매번 자동으로 건너뛰기** (0.7.232): 다음 내 차례까지 건너뛰기가 내 차례 뒤 저절로 다시 건너뜁니다.

## 고친 문제

- F9·F7이 Num 4~6 타구 프리셋이나 최종 타구 벡터 관측기보다 나중에 켜면 거부되던 문제, 관전 모드와 자동 경기로 끝까지의 켜는 순서 문제(0.7.234).
- 지명 보호가 ON으로 보여도 1라운드 입찰에서 CPU가 보호 후보를 지명하거나, 세이브를 다시 불러오면 조용히 꺼지던 문제(0.7.234).
- 구종 칸별 시각 효과의 입자 생성 방식, 같은 설정을 다시 보낼 때 게임 안에 메모리가 쌓이던 점, 켜져 있어도 OFF로 보이던 스위치(0.7.234).
- 스타 최종 능력 확인 화면에서 작성 중 선수 편집이 거부되던 문제(0.7.232), 직접 조작 수비수 LAB을 켜면 공을 잡은 수비수가 송구하지 않을 수 있던 문제(0.7.232), 어필 화면 인식(0.7.229).

## 옵션을 고르지 않아도 달라지는 점

- 검토된 게임이 2.3.0으로 바뀌었습니다. 2.2.0 게임에서는 확인되지 않은 버전으로 안내합니다.
- 유저 옵션·카메라(#700000), 스타플레이어 확장 관리(#740001), 홈런 세리머니·NPB 뉴스(#5920) 원래 패널이 LAB › 옮긴 원본으로 옮겨 갔고 예전처럼 작동합니다. 새 화면과 한쪽만 켤 수 있습니다.
- 다시 켠 Studio의 카드 입력 칸이 기본값 대신 지난번 값으로 채워집니다(게임에는 쓰지 않음). 저장만 되고 카드로 돌아오지 않던 '이 기능 설정 저장' 값 11가지도 돌아옵니다.
- DIRECT 시즌 기록·OPS와 세이브 편집의 기록이 게임 자체의 볼넷·타수 규칙을 써서 일부 선수의 숫자가 바뀔 수 있습니다.
- 드래프트의 ☆/★ 내 후보 화면을 뺐습니다(저장 파일은 그대로).
- 거부 문구에 같은 자리를 쓰는 기능 이름이 나오고, Ctrl+K·켜진 기능이 더 많은 기능의 자기 화면을 엽니다. 세 편집 탭의 기존 카드는 새 외모·능력 복사 아래로 내려갔습니다.
- DIRECT 기능을 켜고 끌 때의 게임 정지 시간과 반복 읽기를 줄였습니다(결과 같음).

이 밖의 명령·단축키·기본값·저장 형식·화면은 0.7.224와 같습니다.

## 설치와 확인 범위

게임 세이브를 따로 백업하고 Studio를 메뉴에서 정상 종료한 뒤 새 EXE를 사용하세요. 설정 폴더나 게임 파일을 지울 필요는 없습니다. Windows x64의 .NET 6 Desktop Runtime x64와 WebView2 Runtime이 필요합니다.

코드·UI·배포 패키지·롤백·단일 EXE 검사와 기존 기능의 회귀 검사, 2.3.0 게임 파일 대조를 통과했습니다. 2.3.0에서 각 기능을 켜고 효과를 본 뒤 끄고 저장·재접속하는 실제 게임 확인, 2.3.0 세이브를 고친 뒤 게임이 불러오는지, 드래프트 회의, 트레이드, 새 화면들은 아직 확인 중입니다. 이상하면 기능을 하나씩 켜서 확인하고, 같은 게임 코드를 바꾸는 다른 CT·트레이너를 동시에 쓰지 마세요.
