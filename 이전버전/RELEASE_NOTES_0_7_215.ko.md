# PROSPI 26 STUDIO 0.7.215

직전 공개판 0.7.213 이후의 **0.7.214~215** 변경을 포함합니다. 로컬·오프라인 싱글플레이 전용입니다.

## 새로 추가된 기능

- **선발 아닌 날 불펜 대기 (스타, LAB):** 선발 투수형 스타가 선발 등판일이 아닌 경기일에 시합을 고르면 결과만 보는 대신 벤치(불펜)에서 실제 경기로 진행합니다. 등판은 감독 판단이나 난입·교체 LAB 요청으로. 다음 선발 등판일은 그대로.
- **자유행동일 여러 번 행동 (스타, LAB):** 자유행동일에 사생활 행동을 하루 N번(기본 2번 = 오전·오후).
- **일정 탭:** 스타·페넌트·고시엔의 경력 달력에 내 팀 경기(홈/원정·상대)와 날짜별 계획.
- **내 쪽 타구만 직접 수비 (LAB):** 내 선수에게 오지 않는 타구는 CPU가 대신 수비(0.7.215 기본 판정: 내 포지션).
- **단축키 배치:** 풀사이즈(기본) / 텐키리스(Alt + 숫자) / 텐키리스(Ctrl + 숫자).
- **모션 LAB:** 폴리곤 인체 편집, 편집본 CHK 내보내기, 원본 CHK 적용·빈 슬롯 저장·복구(게임 종료 상태), **새 폼 파일**을 폼 번호에 등록(모든 모드), DIRECT 투구폼 번호.
- **화면:** 스타·고시엔 한눈에 보기, 예전 패널 기능의 Studio 카드, 모드별 즐겨찾기 창, 뒤로 가기, 세이브 편집 선수 신상·고향·기록·이름·상태.

## 개선된 기능

- **자동 경기로 끝까지(고속 경기):** 온라인을 뺀 모든 오프라인 모드·플레이 형태·투구/타격/주루/수비로 확대(일반 모드만 선택 가능, 켜진 채 전환).
- **경기 메뉴 감독 기능:** 적용 범위 선택 추가(기본은 예전과 같음, 모든 오프라인 모드 선택 가능).
- **F8:** 1루수~우익수로 수비만 할 때도 감지해 수비 가속·송구 속도 전환.
- **코드 자리 부족:** 게임 연결 때 기능 코드 자리를 미리 확보(0.7.214), 내장 CT 레코드도 사용(0.7.215), 실패 시 원인과 해결법 표시.
- 추가 구단을 DIRECT·스타 리그·세이브 편집에서 인식.

## 고친 오류

- 자동 경기로 끝까지를 켜도 일시정지 메뉴에 행이 **보이지 않던** 문제(0.7.184~0.7.214).
- 오래 켜 둔 게임에서 번호키 구속·F6 등이 "±2GB 코드 동굴을 할당하지 못했습니다"로 켜지지 않던 문제(0.7.213 제보).
- 내장 CT #5060(베스트 히팅)이 패치 길이를 잘못 계산하던 문제, #730001 03페이지가 성향·코스를 다른 위치에서 읽던 문제, '적극 주루'가 다른 칸(고시엔에서는 다음 부원)을 쓰던 문제.

## 설치와 확인 범위

게임 세이브를 따로 백업하고 Studio를 메뉴에서 정상 종료한 뒤 새 EXE를 사용하세요. 설정 폴더나 게임 파일을 지울 필요는 없습니다. Windows x64의 .NET 6 Desktop Runtime x64와 WebView2 Runtime이 필요합니다.

코드·UI·배포 패키지·롤백·단일 EXE 검사와 기존 기능의 회귀 검사를 통과했습니다. 새 LAB의 실제 경기 확인(불펜 대기, 자유행동일, 수비, 특수 모드의 고속 경기, 새 폼 파일)은 아직입니다. 새 기능은 별도 세이브에서 먼저 확인하세요.
