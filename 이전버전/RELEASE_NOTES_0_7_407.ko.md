## 바뀐 것 (0.7.407)

- **기록의 올스타 화면 센트럴 지명타자 칸 (0.7.407)**: 센트럴 리그 DH 제도 카드의 ‘올스타전에도 센트럴 DH 부문 (팬 투표·선수 선발)’을 켜 두면, 투표에 이어 기록의 올스타 화면에도 센트럴 리그의 지명타자 칸이 퍼시픽처럼 나옵니다(GitHub 이슈 #15 추가 제보, 페넌트·스타). 그 시즌에 지명타자가 뽑혀 저장된 경우에만 칸이 나오고, 지명타자 기록이 없는 시즌은 원래처럼 센트럴 칸만 보입니다. 올스타 투표와 선발은 지금까지와 같습니다.

예전과 달라지는 점(0.7.406 대비): 기록의 올스타 화면은 ‘올스타전에도 센트럴 DH 부문’을 켰을 때만 달라집니다(기본 끔). 끄면 0.7.406과 같습니다.

## 문제 제보 방식 (0.7.405부터)

- Studio와 CT 둘 다 수만 줄 규모의 큰 프로그램이 되어, 실제 로그와 화면 캡처 없이 설명만으로는 문제를 찾아 고치기가 거의 불가능합니다.
- 그래서 갤러리 댓글로 주신 제보·요청에는 대응하지 않습니다. 문제는 [GitHub 이슈](https://github.com/PrimeTimerer/ProspiStudio/issues)에 올려 주세요. 갤러리라면 최소한 따로 글을 쓰고 아래 자료를 모두 붙여 주셔야 확인할 수 있습니다.
- 함께 올릴 것: Studio 버전, 게임 모드와 상황(경기 중인지 메뉴인지 등), 켠 기능(카드·LAB 이름과 설정), 문제가 생기기까지의 순서, 화면 캡처(Studio 화면과 게임 화면), 로그 파일, 게임이 튕겼다면 크래시 파일
- 로그: `%LOCALAPPDATA%\Prospi26Studio\logs` 폴더의 최근 파일(빅리그식 조작 시스템의 ‘로그 폴더’ 버튼으로도 열립니다)
- 크래시 파일: `%LOCALAPPDATA%\prospi\Saved\Crashes`에서 가장 최근 폴더를 통째로 압축(UE4Minidump.dmp 포함)
- 0.7.406과 0.7.407도 화면 캡처와 Studio 버전이 정확히 적힌 GitHub 이슈(#15)와 그 이슈의 확인·추가 제보 덕분에 바로 원인을 찾아 고쳤습니다.

## 아직 확인 중인 것

- 기록의 올스타 화면: ‘올스타전에도 센트럴 DH 부문’을 켠 시즌에 뽑힌 센트럴 지명타자가 기록의 올스타 화면 지명타자 칸에 나오는지(페넌트·스타)
- 베스트 나인 화면(0.7.406): 페넌트에서 센트럴 지명타자 수상자가 지명타자 칸에 나오는지(스타는 제보해 주신 분이 확인)
- 무조건 파울: 내 타석과 ‘CPU 타자 포함’의 CPU 타석에서 맞힌 공이 파울로 돌아가 타석이 이어지는지
- 스타 트레이드: 신청한 선수가 다음 날 시작 때 우리 구단으로 옮겨지는지, 게임 트레이드 소식과 그날 오더, 저장 뒤 다시 불러오기, 게임 규칙에 걸린 신청의 안내
- 매트릭스를 켠 상태의 빅리그식 타격 파울팁이 파울로 남는지
- 투구 게이지를 끄고 빅리그식 타격만 켠 경기, 투구 게이지만 켜고 타격 탭을 끈 경기
- 자동 업데이트: 0.7.406에서 이번 버전으로의 실제 업데이트
