# PROSPI 26 STUDIO 0.7.223

직전 공개판 0.7.222 이후의 개발분과 중단됐던 작업을 통합했습니다. 로컬·오프라인 싱글플레이 전용입니다.

## 수정

- 투구 자동이 페넌트·엑시비전에서 준비 상태 0x11·0x15를 종료로 오인하던 경로를 수정했습니다. CPU 투구 숫자는 실제 던진 공 수가 아니라 제어를 맡긴 횟수입니다.
- 스타 본인 하루 훈련과 스타 확장 관리가 같은 코드 위치를 사용하던 충돌을 해결했습니다. 함께 켰을 때 효과가 합성될 수 있으므로 낮은 배율부터 사용하세요.
- 모션 목록의 빈 항목 때문에 읽기가 예외로 끝나던 문제, 손상된 목록을 빈 목록으로 덮어쓸 수 있던 문제, 폼 파일 복구 후 적용이 다시 살아나지 않던 문제를 수정했습니다.
- 드래프트 보호·추첨 카드의 바로가기를 수정했습니다.

## 추가

- 시즌 기록에서 OPS·장타율·출루율·ISO 등 게임 내 데이터 기반 지표와 CSV.
- 후보 여러 명의 CPU 드래프트 지명 보호.
- 전체 × 모드 훈련 배율, 고시엔 선택 능력 XP, 스타 본인 훈련·강화 장비 효과.
- 스타 리그의 훈련 배율·매일 성장·성장기 유지·판정 나이·성장 타입 카드.
- 리그 성장 최대치에서 멈추기와 다음 날짜 이월(게임 연결 중 보관).
- 다이제스트 중 내 스타 타석 직접, 시즌 다이제스트·포스트시즌 전체 경기.
- DIRECT·세이브 체격 22항목, 키·체중. 새 폼 파일을 특정 선수들에게만 연결.
- 전술 카드 화면 진단·복구 선택 옵션과 다른 선수 차례 건너뛰기 B안.
- 세이브의 학교 랭크 연동·드래프트 후보 편집.

## 기본값과 검증 범위

새 스위치는 기본 OFF이고 기존 F6·F7·F8, 수비·송구·주루 속도의 기본 범위를 좁히지 않았습니다. 기존 설정·세이브를 지울 필요가 없습니다. 성장·능력 변경은 OFF만으로 복원되지 않으므로 게임 세이브를 백업하세요.

자동 테스트에서 실제 게임 코드가 포함된 격리 실행과 쓰기·복원 경로를 확인했습니다. 자연 경기에서의 투구, 도루 후 표시 복귀, 건너뛰기 복귀, 모션 로딩, 체격 반영, 성장·저장 후 재접속은 별도 확인이 남아 있습니다. 실시간 궤도 색·크기, 주루 모션, 캐릭터 4축 레벨은 연구 단계이며 완성 기능으로 포함하지 않았습니다.
