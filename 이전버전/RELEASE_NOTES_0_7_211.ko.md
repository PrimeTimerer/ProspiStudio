# PROSPI 26 STUDIO 0.7.211

직전 공개판 0.7.208 이후의 **0.7.209~211** 변경을 포함합니다. 로컬·오프라인 싱글플레이 전용입니다.

## 다운로드와 사용법

- Assets의 **Prospi26Studio.Single.exe**를 받으세요. Source code 압축파일은 실행파일이 아닙니다.
- [전체 사용법과 변경 기록](https://github.com/PrimeTimerer/ProspiStudio)
- [PDF 사용 설명서](https://github.com/PrimeTimerer/ProspiStudio/blob/main/manual/PROSPI26_Studio_0.7.211_사용설명서.pdf)
- [0.7.159~0.7.211 변경 기록](https://github.com/PrimeTimerer/ProspiStudio/blob/main/CHANGES_0_7_159_TO_211.ko.md)

## 오늘 추가·개선된 기능

- `Ctrl+Num 1~9`와 `Ctrl+Num *`는 해당 번호키 기능을 홈·원정과 선택 명단에 관계없이 **양 팀**에 적용합니다. **번호키·[*] 내 팀 전체**는 따로 켜는 옵션이며 기본 OFF라 기존 번호키 범위가 유지됩니다. F6·F7·F8 및 수비·송구·주루 속도의 기존 적용 범위는 바뀌지 않았습니다.
- 스타플레이어 확장 내장 패널 #740001의 **자동 ON 요청** 저장 줄을 다시 열 때 복원합니다. 해당 레코드 Auto ON이면 시작할 때 패널을 엽니다. 다른 패널은 종전 방식입니다.
- 페넌트 드래프트에 현재 게임이 공개한 후보를 보는 **게임 목록**을 추가했습니다. 저장된 전체 후보 목록은 계속 기본 보기입니다.
- 페넌트·스타의 고시엔식 전술 경기 LAB에서 수비 지도 위치와 상황 메시지, 삼진 뒤 다음 타자 등장 건너뛰기를 선택합니다. 각각 옛 표시·연출로 돌릴 수 있습니다.
- DIRECT **특능·오리변 가져오기**에서 현역·OB·해외·WBC·국가대표·커스텀·다운로드 원본의 특능·오리변만 고른 선수나 고시엔 부원에게 선택, 미리보기, 적용, 직전 되돌리기를 할 수 있습니다. **0.7.211은 같은 방향의 서로 다른 오리변 두 개를 한꺼번에 선택하면 둘째가 건너뛰어지던 오류를 수정했습니다.**
- 성장 기능 등이 코드 자리를 찾지 못할 때 그 자리를 쓰는 기능·패널·외부 변경을 가능한 범위에서 안내하고, 원복 뒤 다시 찾습니다.
- 게임 실행파일 확인이 오래 걸려도 Studio 화면은 먼저 열리고 확인 중에는 읽기 전용으로 기다립니다. 시작·게임 연결이 세 번 연속 실패하면 바탕화면 진단 보고서 저장 여부를 묻고, 호환성 화면에서 직접 저장할 수도 있습니다.
- 검토되지 않은 실행파일에서는 선택형 **관대 호환 모드**로 기능을 시도할 수 있습니다. 0.7.210부터 선수 편집기와 내장 패널도 열립니다. 이들은 2.2.0 주소·구조로 동작하므로 변경된 게임에서는 빈 목록, 이상값 또는 멈춤·종료가 생길 수 있습니다. 기본 OFF이며 켤 때 이유를 안내합니다.

## 설치와 확인 범위

게임 세이브를 따로 백업하고 Studio를 메뉴에서 정상 종료한 뒤 새 EXE를 사용하세요. 설정 폴더나 게임 파일을 지울 필요는 없습니다. Windows x64의 .NET 6 Desktop Runtime x64와 WebView2 Runtime이 필요합니다.

코드·UI·배포 패키지·롤백·단일 EXE 검사와 기존 기능의 회귀 검사를 통과했습니다. 실제 게임의 모든 모드·경기·시즌, 저장 후 재접속, 게임 업데이트 후 관대 호환 모드의 안정성을 검증했다는 뜻은 아닙니다. 새 기능은 별도 세이브에서 먼저 확인하세요. 기존 0.7.208 화면 이미지는 게임 미연결 예시입니다.
